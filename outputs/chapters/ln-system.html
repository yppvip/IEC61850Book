1. 类、实例、包含与继承

“继承”是某类沿用上位类规定的数据/服务；“包含”是一个对象有下一级对象；“引用”是用标识指向另一份定义。把 XCBR 放在 LLN0 下面画继承树是错误的：它们同属某个 LD，但 XCBR 并非继承 LLN0。

本工程 ChaPTOC1 的 desc 声明“充电过流I段”，可说明该配置的文字标注；不能把所有名为 ChaPTOC1 的其他工程也自动解释为同一业务。

2. 六类信息如何一起读

分类作用与更新特点例子 / CDC怎样使用
公用 LN 信息与具体保护/测量功能相对独立的模式、行为、健康、铭牌Mod/INC、Beh/INS、Health/INS、NamPlt/LPL先认识节点自身
状态信息就地产生，正常读/报告；需要取代时另有机制Str/ACD、Op/ACT、EnaCls/SPS启动、动作、许可不是同一事件
定值功能运行参数，通常不频繁修改StrVal/ASG、OpDlTmms/ING是否分组由 CDC、FC、SGCB 与实现决定
测量值过程量或计算量，正常不可当普通控制命令写入MMXU.A/WYE、TotW/MV结合单位、品质、时标与测量方法
控制命令改变操作状态/位置或执行复位XCBR.Pos/DPC、TapChg/BSC按控制服务与 ctlModel 操作，反馈另读
计量值一段时间的累计量，例如电能MMTR.TotWh/BCR计数、冻结、复零、倍率一起读

这些是第 5 章的数据用途分区；FC（Functional Constraint）是属性的功能约束，二者不是一一等同。一个 DPC 同时含状态反馈 ST、命令 CO 和配置 CF。定值对象可能含 SP，也可能参与 SG/SE 的定值组视图。

3. M/O/C 与 T

标记完整含义本版规则与例子
MMandatory / 必备该具体类实例须包含该项；公共必备数据除 LPHD 外继承
OOptional / 可选类允许采用；具体实例有无沿 LNodeType 查询
CConditional / 条件性本节点说明指定的一组至少使用一个，如 PTEF.Str/Op
C1 / C2不同的条件组RPSB 的检测用途与滑极用途分别说明
TTransient / 瞬态针对 FC=ST 的布尔处理：真→假复位不产生该瞬态的事件报告/日志；不能仅靠轮询捕捉瞬态
空白 T 列未标该瞬态特性不能从“Op”名称自动补 T

7-4 DO 的 M/O/C 不应替代 7-3 DA 的存在条件。DO 可选且实际已实例化时，内部必须出现的 DA 仍须按 CDC 实现。T 也不等同于 SCL 的 dchg/qchg/dupd 或 TrgOps，后者决定事件类别与服务配置。

4. Mod、Beh、Health 与外部设备

数据区分深入阅读
Mod / BehMod 是模式请求，Beh 是结合上层后的实际只读行为五种模式与 25 种组合
Health / PhyHealth / EEHealth功能健康 / 物理设备健康 / 外部设备健康三种健康状态
NamPlt / PhyName / EEName节点铭牌 LPL / 物理设备铭牌 DPL / 外部设备铭牌 DPLLPL 与 DPL
Loc就地/远方；LLN0 与 LN 冲突时就地优先不是通用的访问权限凭证

公用可选项在具体类中可不继承、继承为可选或要求为必备；例如 XCBR 的 Loc/OpCnt 为 M，不能仅看公用模板中的 O。

LPHD：物理设备信息

Physical device information；反映实际物理设备；PhyHealth 与外部一次设备 EEHealth、某功能的 Health 分开读取。Proxy 是该物理设备信息是否作为代理的声明。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
PhyNameDPLM—原表 9 打印 PhyNam，而 LPHD 表打印 PhyName；表示物理设备铭牌。
PhyHealthINSM—物理设备健康状态，编码语义与 Health 相同；不等于外部一次设备健康 EEHealth。
OutOvSPSO—该数据指示输出缓冲区发生溢出，对于通信，重要信号可能丢失
ProxySPSM—为TRUE时表示逻辑节点是代理服务器
InOvSPSO—该数据指示输入缓冲区发生溢出，对于通信，重要信号可能丢失
NumPwrUpINSO—自上次复位以来，物理/逻辑装置加电次数
WrmStrINSO—自上次复位以来，物理/逻辑设备的热启动次数。
WacTrgINSO—自计数器复位以来，监视电路复位装置的次数
PwrUpSPSO—为TRUE时表示检测到装置加电
PwrDnSPSO—为TRUE时表示检测到装置电源断电
PwrSupAlmSPSO—LPHD 所建模 IED 的本地电源告警；不等于整个站外部电源系统的健康。
RsStatSPCOT装置统计复位命令；LPHD 的上下文与 GSAL 监视计数区分。

COMMON：公用逻辑节点信息

Common logical node information；公用逻辑节点信息功能：节点描述对象/状态及相关配置；标准模型不规定完整厂家实现。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
ModINCM—运行模式的可控请求；其枚举和全组合行为见取值页。
BehINSM—只读的实际行为，由逻辑设备 LLN0.Mod 与本节点 Mod 组合确定。
HealthINSM—Health / PhyHealth / EEHealth；编码与完整含义见取值页。
NamPltLPLM—逻辑节点铭牌

EEHealthINSO—外部设备状况信息，如由逻辑节点XCBR控制的断路器
EENameDPLO—外部设备铭牌信息，如由逻辑节点CSWI控制的断路器XCBR
OpCntRsINCO—可复位逻辑节点动作计数

LLN0：逻辑节点零

Logical node zero；逻辑设备的公共信息节点。SCL 用 LN0 元素承载 lnClass=LLN0；不是 lnClass=LN0。服务控制块位置需沿实际 SCD 核对。
