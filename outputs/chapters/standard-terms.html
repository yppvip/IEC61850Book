1. 本章位置与使用边界

本章以“变电站通信网络和系统 第 2 部分：术语”的主题为线索，整理 SCD 阅读中高频出现的术语与缩写。中文解释为原创导读，不重印标准定义；缩写的精确用法、某一版次的适用范围和设备支持项，仍应以项目引用的标准、ICD 和一致性声明核对。

阅读线索：LN → DO → DA 定位数据；FC 说明数据用途；FCD / FCDA 把要交换的数据写入 DataSet；GOOSE 将这个数据集按发布订阅方式快速传送。

2. 四个容易混淆的“功能约束”术语

术语英文 / 缩写含义与功能在 SCD 中怎样识别
功能约束Functional Constraint（FC）给数据属性标出其服务用途，例如状态、测量、控制、设置或描述。它帮助客户端区分“同一数据对象内哪类信息可如何访问”，不是保护功能，也不是网络优先级。常见于模型定义中的 DA@fc，或数据集成员的 FCDA@fc。
功能约束数据Functional Constrained Data（FCD）按功能约束可访问的一组数据概念；可理解为“某个 LN/DO 在某个 FC 下的数据视图”。它用于抽象服务模型中描述数据访问范围。它是模型/服务术语，不是 SCL 中独立的 XML 标签；工程中通常由 LN、DO 和 FC 共同定位。
功能约束数据属性Functional Constrained Data Attribute（FCDA）FCD 继续精确到数据属性的引用。其作用是准确选定 DataSet 内一个成员，让报告、GOOSE 或 SV 控制块知道要交换哪项数据。<FCDA ldInst="…" lnClass="…" doName="…" daName="…" fc="…"/>；不同数据集的排列顺序也会影响接收侧解释。
数据集Data Set（DataSet）按顺序组织 FCD/FCDA 的清单，是报告、GOOSE、SV 等服务的内容来源。它不是网络地址，也不能单独证明另一 IED 已订阅。通常位于 LN0/LN 的 DataSet；再由控制块引用。
不要只看 FCDA 的名称。须同时确认它所在的 DataSet、控制块、发布端通信配置和接收端 ExtRef；同名 DO/DA 在不同 LD、LN 实例中可以是不同对象。

3. 常用 FC 的阅读方向

STStatus information运行状态，例如位置、告警或保护起动相关状态。
MXMeasured values测量值；同时查看数值、单位/倍率、质量 q 与时标 t。

SP / SG / SESet point / Setting group / Setting group editable设置值、设置组及可编辑设置；不可把它们直接当成实时测量值或已生效整定。
CFConfiguration配置性质的信息；变更应纳入工程基线和授权流程。
DC / EXDescription / Extended definition描述或扩展信息；其存在不等于运行数据。

4. 通用面向变电站事件对象（GOOSE）

Generic Object Oriented Substation Event（GOOSE） 是面向变电站的通用对象事件发布订阅服务。发布 IED 把一个 DataSet 关联到 GSEControl，并在通信配置中给出 GSE 网络参数；接收 IED 通过输入引用建立订阅。它常用于保护跳闸、闭锁、失灵起动、开关状态和联锁等对时效性敏感的信息交换。

相关缩写作用
GSEControlGOOSE 发布控制块，引用发布的 DataSet。
GSE通信配置中的 GOOSE 网络侧信息，关联发布控制块和地址参数。
ExtRef接收侧外部引用；用于把输入映射到发布数据，必须与订阅关系整体核对。
APPID / VLAN工程网络识别和隔离/优先级参数；不是业务含义的可靠推断依据。

5. 与 SCD 密切相关的缩写

缩写英文全称在 SCD 中的重点

SCD / ICD / CIDSubstation Configuration Description / IED Capability Description / Configured IED Description分别面向全站配置、IED 能力和下装 IED 的配置文件；用途与流转边界不同。
IED / LD / LNIntelligent Electronic Device / Logical Device / Logical Node设备、逻辑设备和功能模型层级。

FCDAFunctional Constrained Data AttributeDataSet 的精确成员引用，是发布订阅追踪的关键锚点。
