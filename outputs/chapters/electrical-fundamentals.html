电气基础：从电路到三相功率

把电压、电流、频率、功率和电能变成可解释的数据。

电网在输送什么：回路、电压与电流

发电侧把其他形式的能量转换为电能，经输电、变电、配电送到负荷。变压器改变电压等级；相同有功功率和功率因数下，提高输送电压能减小电流，从而降低导体的 I²R 损耗。它不凭空产生能量。

电压 U 是两个点之间的电势差，单位 V；电流 I 是电荷流动的速率，单位 A。电流需要闭合路径，不能只看一条出线就认为没有回路。一次单线图把三相画成一条线，回路的中性点、接地、相间返回路径须结合接线方式理解。

概念入门关系使用条件与开发提示
电阻 R / 阻抗 Z直流电阻：U=IR；正弦稳态相量：U̲=Z̲I̲Ω。交流中 R、感抗和容抗共同影响幅值、相位；不要对故障波形直接套稳态比值。
节点电流 / 回路电压按约定方向，节点电流代数和为 0；闭合回路电压代数和为 0是电路建模关系；测量误差、互感器变比和相位须另处理。
额定值 / 实测值 / 定值设备标称能力 / 当时测量 / 保护控制参数额定 600 A 不表示一直流 600 A；整定阈值不是实时电流。
一次 / 二次主电力回路 / 测量保护控制回路“二次值”也可特指互感器输出值，要说明语境。

交流、有效值和相量

正弦量可写为 u(t)=√2·U·sin(2πft+φ)，其中 U 为有效值（RMS），f 为频率，φ 为相位。50 Hz 的周期为 20 ms，这只是本页教学条件。有效值反映与相同电阻发热等效的大小；纯正弦时峰值=√2×有效值，有直流偏置或谐波时不能照搬。

相量用幅值和角度表示同一频率的正弦量，适于比较电压、电流相位；它不是一帧 SV 中的瞬时采样点。SV 提供采样序列，装置算法根据窗口计算 RMS、相量、功率等。窗口、滤波、基准角和更新周期不同，结果可以不同。

开发人员要先问“这是瞬时值、RMS、基波相量还是统计量”，再讨论数值是否一致。深入见M 组的相量、谐波与统计窗口。

三相：相量差产生线电压

三相交流的三组相量在理想对称系统中依次相差 120°。以对称星形相电压为例，线电压 UAB 是 UA 与 UB 的相量差，因此线电压有效值 UL=√3·Uph。相序表示三相达到相同相位的先后次序；相别、相序和电流正方向必须独立记录。

场景关系不能省略的前提
对称星形连接UL=√3·Uph；IL=Iph相电压指相对星点；对地电压还取决于中性点接地及运行状态。
对称三角形负载UL=Uph；IL=√3·Iph这里的相量是负载支路量，不要把“相电流”直接等同于线路导体电流。
三相不平衡 / 接地故障逐相/序分量分析不能用一个单相量乘 √3 概括全部状态；零序回路取决于接地和变压器接线。
三相残流Ia+Ib+Ic=3I0（相量和）不是三相 RMS 幅值直接相加；CT 极性、接线和专用零序 CT 也影响读数。

例如对称星形系统 UL=10 kV，则 Uph≈5.77 kV。“10 kV”在系统标称语境通常指线电压，但具体数据对象仍要核对量定义。详见序分量与相量参考。

有功、无功、视在功率与电能

在对称三相、正弦稳态条件下，用线电压 UL、线电流 IL 的有效值，有 P=√3·UL·IL·cosφ，Q=√3·UL·IL·sinφ，S=√3·UL·IL，且 S²=P²+Q²。有功 P 对应平均能量转换；无功 Q 描述储能元件与电源间的周期性交换；视在 S 反映电压与电流对设备容量的要求。

量单位看数据时要问什么
P / Q / SW / var / VAk、M 倍率是什么？正负方向按发电、受电还是指定参考？
功率因数 PF无量纲，通常 P/S非正弦时不能总当作基波 cosφ；确认是否位移因数。
有功电能 E=∫PdtWh / kWh累计方向、起算点、冻结时间、复位/回卷和倍率是什么？
频率 fHz测量窗口与品质怎样？50 Hz 是此例条件，不是所有系统唯一值。

原创算例：UL=10 kV、IL=200 A、cosφ=0.9（电流滞后）时，S≈3.464 MVA、P≈3.118 MW、Q≈1.510 Mvar。若有功保持 2 h，电能约 6.235 MWh。读数变成 kW 后应约为 3118，不能把它当成 3.118 W。

公式原理核对：Electrical Installation Guide 功率关系。数值为原创算例，不用于设备选型或整定。

正常、过载、短路和接地不是同一件事

状态物理含义为什么保护逻辑不同
正常负荷在运行约束内供给用电设备电流非零通常是正常状态，不能“有电流就报警”。
过载超过允许负载或热能力往往考虑热积累与持续时间；不能只比较一次瞬时峰值。
短路不同电位点形成异常低阻通路可能造成大电流、电压跌落和暂态，但故障电流受电源与阻抗限制。
接地故障带电回路与地出现非预期通路大小与特征受中性点接地方式影响，不能一概认为都是很大的电流。
测量/通信异常物理过程可能正常，观测链却失真或失效不能把无效值、缺数据当作 0 A 或断电。

这些区别决定要读哪些测量量、序分量、保护起动和质量信息。保护功能的完整设计还需系统分析，继续看保护原理与动作链。
