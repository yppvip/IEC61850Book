保护 IED 类型、部署与命名

先按一次对象定位保护，再把装置名称、模型与试验边界放回工程证据链。

1. 阅读边界：类型不是定值方案

保护装置通常按被保护的一次对象和保护功能组合部署。以下内容说明典型位置、常见关注量、可能出现的 IEC 61850 LN 类和常见试验方向；它不提供定值、出口接线或投运结论。实际配置受电压等级、接线、运行方式、双重化、厂商实现和项目规程影响。

识读顺序：一次对象/保护范围 → 保护功能与后备关系 → IED 数据模型和通信引用 → 设计图、定值单、逻辑图与经批准试验记录。

2. 常见保护 IED 与部署位置

类型典型部署位置主要功能与常见监测量常见试验方向
线路保护线路间隔，两端或多端按方案配置。距离、纵联/差动、方向过流、接地、重合闸；相/零序电流、电压、阻抗、方向与通信通道状态。常见 LN：PDIS、PTOC、PTRC、RREC。继电特性、方向/距离判据、通道配合、重合闸、跳闸与远方/本地联动。
断路器失灵保护断路器间隔或保护集成单元，关联相邻断路器跳闸范围。当跳闸命令已发出而故障电流/位置状态未按时消失时起动后备切除；关注跳闸命令、电流、断路器位置与时间逻辑。失灵起动、延时、再跳与联跳范围、开入/开出回路及反馈。
变压器保护主变本体及高/中/低压侧相关保护屏或 IED。比率差动、后备过流/接地、过励磁、温度/瓦斯等本体信号；关注各侧电流电压、相位补偿、分接头及本体告警。差动制动特性、CT 回路与相位、各侧后备、非电量跳闸及联跳。
母线保护母线保护屏/IED，覆盖一个母线段及其间隔 CT。母线差动与检查/闭锁逻辑；关注各支路电流、母线运行方式、隔离开关位置和 CT 断线等。区段选择、CT 极性/回路、切换逻辑、闭锁、各出口跳闸范围。
馈线 / 配电保护中低压出线柜、环网柜或配电间隔。过流、速断、接地、方向、重合闸/备自投配合；关注相/零序电流、电压、开关位置。动作时限与选择性、接地判据、开关跳合闸及配合关系。
电容器 / 电抗器保护电容器组或并联电抗器间隔。过流、过压/欠压、不平衡、谐波/过负荷及设备本体保护；关注电流、电压、不平衡量和温度/压力等。不平衡及过压判据、投切闭锁、放电时间与联跳。
发电机 / 电动机保护厂站内发电机或大容量电动机间隔，若工程范围包含该一次设备。差动、失磁、逆功率、过负荷、负序、接地、起动/堵转等；关注电流、电压、频率、功率、转速或工艺信号。保护特性、起动/停机逻辑、与励磁/断路器/工艺系统的联锁。

3. 保护功能的部署关系

常见架构还会采用主保护与后备保护、双重化配置、独立保护与测控一体化等组合。应通过功能配置、跳闸矩阵、SCD 的 LN/GOOSE 引用及设备资料确认，不能仅凭 IED 名称或出现一个 PTOC/PDIF 推断完整保护范围。

4. 中国大陆工程中常见 IED 名称字母（非强制规则）

IED 名称常受设计院模板、厂商工具、站内位号和历史习惯影响，并无一套跨项目强制统一的字母表。下表用于初步阅读，名称只可作为检索线索，必须回到 desc、LN、LDevice、功能图和设备清册确认。

常见片段通常指向例与提醒
PL / LINE线路保护（Protection Line）PL1_A 可能表示线路保护 A 套，但 A/B 的含义以项目双套方案为准。
PT / TR主变保护（Transformer Protection）PTR1 也可能与 IEC LN 前缀混淆，不能只凭字符串判断。
BUS / BB母线保护（Busbar）可能按 I、II 段或母线分区编号。
BF断路器失灵（Breaker Failure）可能是独立 IED、集成保护功能或逻辑名。
BCU / CTRL间隔控制/测控单元（Bay Control Unit）通常偏测控与控制角色，不排除附带保护或联锁功能。
MU合并单元（Merging Unit）常见于过程层采样；不可与测控 IED 或交换机混同。
IT / INT智能终端（Intelligent Terminal）常用于开入开出、位置与跳合闸执行接口。
GW / RTU网关/远动（Gateway / Remote Terminal Unit）常负责对外规约或调度接口，不由名称直接确定实际规约。
A/B、1/2双套、通道、屏柜或实例区分可能是主后备、双重化或仅为编号，必须查项目命名规范。

5. 从 IED 名称走向可验证证据

  1. 用名称和 desc 找到候选 IED；不要把名称当结论。
  2. 检查 LDevice / LN：例如 PDIS、PDIF、PTOC、PTRC、RREC 仅说明相关模型存在。
  3. 沿 DataSet、FCDA、GSEControl 与 ExtRef 核对联跳、闭锁和输入来源。
  4. 最终依据逻辑图、定值单、端子图和授权试验记录确认保护范围、出口和投退状态。
继续阅读：术语：对象、功能约束与 GOOSE → LN / CDC 深度索引 → 安全与测试边界。
