1. 时间模型与时间同步

第 18 章把时间语义、表示、外部时源、站内时间服务器、同步协议和需要时间的 IED 组成一个模型。ACSI 规定 UTC 语义与品质，具体对时协议由 SCSM 定义。时间服务器可与 ACSI 客户/服务器部署在同一硬件中，但它们的角色不同。

组成功能使用场景 / SCD 边界
外部时源提供已知准确度的时间、闰秒信息和时源纪元不能把 GPS 纪元直接当 1970 UTC 纪元；本模型不指定全部硬件接口
站内时间服务器向 IED 提供同步时间当前可用性和时源品质需要运行证据
时间同步协议使客户和服务器的时钟协同8-1 等定义适用机制；后续工程 PTP 属于实际采用规范，不写成此 2003 基线必选
时标语义纪元秒、分数和品质TimeStamp 类型和 TimeQuality；参见公共类型
时标表示映射定义字节/字段EntryTime 与 TimeStamp 未必同编码
时间使用者产生或解释事件、报告、样本和预约动作SCD 类型及选项只说明配置，不证明当前满足性能

SOE（Sequence of Events，事件顺序记录）跨设备排序，须考虑时间准确度和失步；两个相差很小的事件不能只凭显示小数位断定真实先后。SV 协作还需样本计数、采样率和同步；预约控制 operTim 需在正确时间且仍满足动作条件，不能只证明定时器已启动。

核查点含义常见误读
ClockFailure时源不可靠，基线要求忽略该 TimeStamp数值能显示就认为有效
ClockNotSynchronized没有与外部 UTC 同步本地时钟仍在走就认为已对时
TimeAccuracy相对 UTC 的准确度等级当作采样周期或 UI 小数位
FractionOfSecond可表示二进制分辨率60 ns 等于设备测时误差
DATA.t / TimeOfEntry / TimeOfLog分别按数据、报告缓冲和日志语义采用当成完全相同的时间
sampleSynchronized 配置携带/采用同步信息的 XML 配置线索当作当前 SmpSynch=true

2. FILE 类与全部文件服务

第 20 章 FILE 是服务器文件存储中的有序、非结构化二进制字节流，可以包含程序、数据或二者。ACSI 定义传输与存储管理，不定义所有文件内部格式，也不把传输成功等同于设备成功加载配置。COMTRADE 等扰动记录的格式另有规范。

属性基线类型 / 存在值域 / 功能表现样式 / SCD
FileNameVISIBLE STRING255文件存储中的名；分层路径和命名约束按映射教学 /records/event001.dat；不是本站路径
FileSize[0..1]INT32U；0～4294967295以八位位组计的文件长度；生成中文件无法确定时另按实现解释教学 2048 字节；SCD 无全文件目录
LastModified原表 43：TimeStamp最近修改时间人可读日期只是显示形式，运行属性由服务返回
服务RequestResponse+Response− / 用法
GetFileFileNameFile-Data（八位位组串）ServiceError；从服务器向客户获取内容
SetFileFileName + File-Data请求成功ServiceError；从客户向服务器传内容
DeleteFileFileName请求成功ServiceError；删除允许删除的设备文件
GetFileAttributeValues适用 FileName/选择范围，按模型和映射FileName + FileAttribute[1..n]，含长度与修改时间ServiceError；先确认目录和属性

源表部分否定参数写 ServerError，正文说明使用 ServiceError，本页按失败服务语义说明。分段传输、句柄及线上请求可能映射成多个具体服务，不虚构“单个 ACSI 服务必等于单个 MMS 包”。

参考 SCD 有 63 个 IED 的 Services 含 FileHandling。它是工程能力声明，不能证明任意目录可读、任意文件可写，也不能证明采用 FTP/HTTP。将 SCD 作为文件传给设备是否可用，必须按设备明确支持的工程流程确认。

4. 从需求到证据的工程阅读流程

工程目标先读配置再查服务与状态结论边界
读取测量LN/DO/DA 类型、FC=MX、单位/缩放GetDataDefinition、GetDataValues、q/t当前值可信需品质与来源
接收遥信事件DataSet、RCB、DA 和 TrgOps关联、RCB 保留、RptEna、报告字段当前快照和历史恢复分开
恢复 SOEBRCB、EntryID 选项与修订最近 ID、缓存范围与溢出不能保证容量之外的历史
查询装置历史LogControl 及日志目标GetLogStatusValues、范围/增量查询无 Log 元素时先核实运行模型
切换定值组SettingControl、SG/SE 数据激活/编辑/确认各阶段结果编辑不等于生效
解释 GOOSE/SV发布块、成员、通信参数与订阅有效期、修订、测试、同步/连续性地址不等于实际业务含义
解释控制失败ctlModel、CO/CF、反馈对象失败阶段、ServiceError、AddCause不能单个错误名就认定现场故障
取回记录文件FileHandling 与设备文件说明目录、属性、GetFile 结果传输成功不证明格式/内容有效

同一模型变更要同步检查首页/术语、控制块引用、成员顺序、类型和订阅链。离线知识库提供这些静态解释，不执行现场数据访问、抓包、发包或控制，也不替代工程校验和受控试验。
