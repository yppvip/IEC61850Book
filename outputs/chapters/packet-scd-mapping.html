SCD 与报文的双向映射

配置 → 信号 → 编码 → 字段 → 工程证据

本模块使用原创、脱敏、固定教学案例。页面只在本地切换示例和高亮字节；不读取用户抓包、不发送报文。XML 为保留引用链的部分模型，不等同于完整可投产 SCD、设备手册或标准原文。能解释本例不等于完成独立现场分析能力或符合性验证。

1. 共同的原创配置与类型链

案例文件 packet-demo.scd 是保留实例、类型、数据集、控制块和Communication的原创部分模型；XML可读取，但省略标准必选公共对象、完整网络/授时与能力声明等，不作为XSD合格工程。本例所有IED/IP/MAC均人工编写；未读取真实工程来推断业务。

Demo / AP1 / LD0 / XCBR1 [lnType=DemoXCBR]
  LNodeType DemoXCBR → DO Pos [type=DemoDPC]
  DOType DemoDPC [cdc=DPC]
    stVal: Dbpos, FC=ST → GOOSE/MMS BIT STRING 2有效位
    q: Quality, FC=ST → GOOSE BIT STRING 13有效位
Demo / AP1 / SV0 / TCTR1 [lnType=DemoTCTR]
  DO Amp [type=DemoSAV, cdc=SAV]
    instMag: Struct, FC=MX → DAType DemoAnalogue / i: INT32
    q: Quality, FC=MX → SV 4字节映射容器

IED名不是一定等于MMS域名。常规LDName由IED名和ldInst形成，显式LDevice@ldName等情况按适用版本/模型核对。prefixed LN、SDO、BDA、数组或整个FCD都需沿类型展开；本例只演示无数组的明示标量路径。

2. GOOSE 正向映射：逐步点击证据链

SCD / 实例：Demo/AP1 → LDevice LD0 → XCBR1.Pos.stVal；实例lnType=DemoXCBR → DO Pos type=DemoDPC → DA stVal bType=Dbpos, fc=ST。

DataSet：LN0/DataSet@name=dsPos，FCDA[1]=Pos.stVal，FCDA[2]=Pos.q。这里2个标量成员；若删daName改FCD必须重新展开类型。

Control Block：LN0/GSEControl@name=gcbPos, datSet=dsPos, confRev=1, appID=DemoPos；运行时GoCB引用DemoLD0/LLN0$GO$gcbPos。

Communication：ConnectedAP iedName=Demo apName=AP1 → GSE ldInst=LD0 cbName=gcbPos → Address APPID=1001(十六进制)、目的MAC。

报文字段：gocbRef=DemoLD0/LLN0$GO$gcbPos，datSet=DemoLD0/LLN0$dsPos，goID=DemoPos，APPID=0x1001，allData[1]=84 02 06 80(合位)。

反查信号：用发布身份与引用定位唯一控制块，再取dsPos顺序和DemoDPC类型，才能将allData第1项称为本例XCBR1.Pos.stVal。订阅方业务还需Inputs/ExtRef和内部逻辑证据。

<GSEControl name="gcbPos" type="GOOSE" appID="DemoPos" datSet="dsPos" confRev="1"/>

控制块的同名匹配要带上IED/AP/LD/LN作用域，不能只搜索字符串gcbPos。GSE@cbName指控制块名，GSE@ldInst指其所属LD；datSet是发布LN作用域中的数据集名，不是Communication路径。

3. SV 正向映射：不能在每帧找到所有配置

Demo/AP1/SV0/LLN0/DataSet dsSV（16 FCDA）→ SampledValueControl smv01 → SMV ldInst=SV0 cbName=smv01 → APPID=4001与目的MAC → 帧svID=DemoSV1、confRev=1、noASDU=1 → seqData按16个标量成员/八通道解释。datSet字符串与smpRate在此例没有发送，因此不能从Hex中凭空读出它们。

<SampledValueControl name="smv01" smvID="DemoSV1" datSet="dsSV" confRev="1" multicast="true" smpRate="80" nofASDU="1">
  <SmvOpts refreshTime="false" sampleSynchronized="true" sampleRate="false" dataSet="false" security="false"/>
</SampledValueControl>

nofASDU是每帧聚合数，不是DataSet成员数。SMV和SampledValueControl是两个不同配置位置；SmvOpts.dataSet是控制是否传输引用的选项，不能把不含datSet的流当成没有数据集。

4. MMS 对象映射与报告链的分支

直接读：DemoLD0/XCBR1.Pos.stVal [ST] → domain DemoLD0 / item XCBR1$ST$Pos$stVal → ReadRequest → invokeID=1同关联响应 → Dbpos=on。服务端AP/IP配置帮助定位连接，但运行时目录、协商与访问权限仍要查。

报告：同一dsPos还被ReportControl brcbPos引用 → 运行时BRCB与使能 → InformationReport。它不是gcbPos，也不因为数据集相同而自动发送GOOSE。必须查真实RptID、OptFlds、inclusion、confRev、分段与控制块状态；报告中的可选DataRef不是每帧必带。

5. 从 Wireshark 反查 SCD：匹配组合，而非猜名字

观察事实反查路径还缺的证据
GOOSE APPID1001 + gocbRef DemoLD0/LLN0$GO$gcbPos + datSetCommunication/ConnectedAP/GSE → IED/AP/LD/LN0/GSEControl → dsPos → FCDA与类型检查MAC/VLAN、confRev和配置版本；接收Inputs/ExtRef与实际内部映射
SV APPID4001 + svID DemoSV1 + confRev1SMV网络对象 → SampledValueControl smv01 → dsSV → 声明的值/q顺序确认布局、比例、同步模式；没有datSet字符串时不能只凭APPID命名通道
MMS Read domain DemoLD0 + item XCBR1$ST$Pos$stVal已确认服务器/AP → LDName → LN XCBR1 → FC ST → Pos.stVal → 类型关联上下文、动态模型/目录及当前权限；响应按请求结果位置配对
InformationReport只含部分值RptID/可选DataSet、DataRef/配置版本与inclusion → RCB/DataSet运行时使能/触发、缓冲与分段；相同RptID候选需进一步消歧

APPID只在其通信与工程上下文中帮助筛选，不能保证跨子网/多工程全局唯一。发现同名、重复APPID、不同confRev或SCD版本不明，应列出候选和冲突，暂停语义归属。源MAC可能因冗余/实现影响，不能反推厂家功能或跳闸对象。SCD描述预期，抓包描述观测，两者不一致时都不是自动的最终真相。

来源、版次与适用范围

版次与来源边界：以项目既有早期 IEC 61850-8-1 中文资料的传统 MMS/GOOSE 映射为起点，并参照公开解码器 ASN.1 定义核对结构；SV 采用明确声明的 9-2 八通道 INT32/Quality 教学布局。它不是跨版次唯一实现，也不宣称完整符合 9-2LE 或 IEC 61869-9。本地9-2为DL/T 860.92—2006扫描件，本次视觉复核PDF第16～17页（印刷第12～13页）表13/14的容器及基础类型；早期smpSynch为BOOLEAN，本例按较新版公开解码定义的0/1/2枚举解释，1表示local，不能混用。7-2扫描件未逐条核验。公开解码器是交叉核对资料，不能替代适用版次标准。

职责：IEC 61850-6 管配置与交换；7-2 定义 ACSI（Abstract Communication Service Interface，抽象通信服务接口）；7-3 定义 CDC（Common Data Class，公用数据类）；7-4 定义 LN（Logical Node，逻辑节点）及数据对象；8-1 将服务映射到 MMS/传统 GOOSE；9-2 定义 SV 以太网映射。ISO 9506 定义 MMS（Manufacturing Message Specification，制造报文规范）；ASN.1（Abstract Syntax Notation One）描述结构；BER（Basic Encoding Rules）将结构编码为字节。IEC 62351 安全扩展不在本例内。

可选在线追溯（离线阅读不依赖链接）：IEC 标准体系目录 · ITU-T X.690 BER 规则 · Wireshark MMS ASN.1 · GOOSE ASN.1 · SV ASN.1。

显示字段名按公开 Wireshark 参考核对：MMS · GOOSE · SV。具体版本、偏好、上下文可能改变节点名或是否解码；本模块未调用 Wireshark 引擎解码这些合成帧。
