4. 数据集、控制块与接收输入

<LN0 lnClass="LLN0" inst="" lnType="Teaching_LLN0">
  <DataSet name="dsStatus">
    <FCDA ldInst="LD_A" prefix="" lnClass="XCBR" lnInst="1"
          doName="Pos" daName="stVal" fc="ST"/>
  </DataSet>
  <LogControl name="lcStatus" datSet="dsStatus" logName="Events"
              intgPd="0" logEna="true" reasonCode="true">
    <TrgOps dchg="true" qchg="false" dupd="false" period="false" gi="false"/>
  </LogControl>
</LN0>

此片段按参考日志的 dchg=true、qchg=false、dupd=false、period=false、intgPd=0 组合重组为原创示例；数据集内容和名字重新构造，gi=false 显式表达日志不支持总召唤的语义。logName 指向日志对象，不是数据集。若只引用 stVal 且未启用 qchg，不能据此保证品质变化会形成该日志条目。

参考观测可得结论仍不能证明
979 个 ReportControl 全部 buffered=true均选择缓存报告配置类别运行 RptEna、实际缓存量、历史是否丢失
98 个 LogControl 的 intgPd 均为 0未配置非零周期完整性间隔设备是否写入或保留了所需事件
19 个 SampledValueControl 均 smpRate=80、nofASDU=1共同声明采样率参数和每报文 ASDU 数原始传感器采集率、同步质量或通道精度
2658 个 ExtRef 未声明 serviceType 与 src* 字段有外部数据引用，缺少直接源控制块/服务定位不能仅凭 intAddr/名字断言 GOOSE 或 SV 业务

引用链：发布 LN 的 DataSet → FCDA 目标对象；控制块 datSet → 同 LN 数据集；Communication 的 GSE/SMV → 相应控制块；接收 Inputs/ExtRef → 外部 IED/LD/LN/DO/DA。缺少源控制块字段时，要反查所有包含该对象的数据集，保留多个候选而非强行唯一。
