3. 数据集：概念、类别与生命周期

DATA-SET 是至少一个 FCD/FCDA 的有序引用集合。双方已知成员与顺序时，不必每次重复发送全部成员名字。一个 DATA/DA 可被多个数据集引用，成员不是新建业务数据副本；数据集可以跨 LN、按适用规则引用 LD 中的成员。DataSet 名本身不能证明用于何种业务，必须查控制块或读写引用。

4. 取代：改变数据来源，不直接操控一次设备

取代用指定值与品质替代 ST/MX 数据对外呈现的过程值。常见场景是受控地处理异常或失效数据源。该机制不等于写 stVal、不等于测试模式，也不保证改变外部设备真实状态。原文明确取代属于正常操作模型，测试另由模式或服务 Test 参数表达。

属性类型 / FC作用使用顺序
subVal / subMag / subCMag随 CDC 的值/结构类型；SV待取代的状态、幅值或复数量先准备替代值
subQQuality；SV替代品质与值共同准备，按模型反映来源/有效性
subIDCDC 规定字符串；SV标识启动取代者按应用规程设置
subEnaBOOLEAN；SVtrue 采用替代值，false 恢复过程来源准备值/品质/标识之后再使能
原创教学顺序（只解释服务，不提供操作功能）：
1. SetDataValues 写 subVal/subQ/subID（FC=SV）
2. SetDataValues 写 subEna=true（FC=SV）
3. GetDataValues 或报告读取 ST/MX 视图及品质
4. 退出时将 subEna=false，并核对恢复后的来源/品质

本模型复用数据读写服务，没有独立“Substitute”报文。关联断开不能自动推断取代立即退出；保持/退出需核对当地行为。参考 SCD 类型库包含 subEna BOOLEAN、subVal BOOLEAN、subQ Quality、subID VisString64，FC 均为 SV；类型存在不证明当前已取代。

5. 定值组：编辑、确认与激活分开

SG 是一组共同切换的参数值，SGCB 管理多个组及激活/编辑缓冲。同一 LD 的多个 LN 可以共用一个定值组控制过程。当前激活组以 FC=SG 读；选定编辑组后以 FC=SE 访问编辑缓冲，确认后才把缓冲提交到该组，激活又是另一项服务。

6. 报告：BRCB、URCB 与恢复

报告由服务器向客户主动发送数据集变化或完整快照。Report 本身是无确认 ACSI 服务，传输层可靠性不能替代客户端入库证明。一个报告实例在同一时刻受一个客户使用/保留；多客户接收通常需要可用实例或映射规定的客户视图。

SmpRateINT16U按选项携带；单位依实际采用规范

参考 smpRate=80、nofASDU=1。在额定 50 Hz、SmpPerPeriod 且每次一个样本的教学前提下，80×50=4000 样本/秒；文件本身不能证明所有这些现场前提。SmvOpts.sampleSynchronized=true 是配置字段选择，不是同步成功证明。参考出现 dataRef，而既有 B4 模式核对使用 dataSet，这一差异保留，不静默修复原 SCD。详见 采样控制块与 B4 字段。

10. 控制：普通/增强安全、直接/SBO 与时间激活

Control 对可控 DATA 发出动作请求。普通/增强安全是控制模型的行为分类，不等于密码强度或网络加密。SBO 防止其他客户在有效选择期间竞争；增强安全增加带值选择及最终命令终止语义。收到 Operate 成功响应还不能据此宣布一次设备已到位。
