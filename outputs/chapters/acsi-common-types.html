ACSI 基本类型、公共类型与对象引用

从信息对象，理解服务、配置引用和运行行为。

阅读位置与版本

上级：第 7-2 部分：ACSI。按“概念 → 属性与服务 → SCD 证据 → 工程使用”阅读。

标准基线：DL/T 860.72—2004（等同 IEC 61850-7-2:2003）；参考 SCD 为 SCL 2007 B4。抽象模型、协议映射、XML 配置和设备运行值分别解释。本文为原创导读，工程摘录保留源文件关键字与名称，不是完整可投产配置。

3. 对象名、对象引用与语法

ObjectName       = 单个层级实例名
ObjectReference  = LDName/LNName[.Name[...]]
LDRef            = LDName
LNRef            = LDName/LNName
DataRef          = LDName/LNName.DataName[.DataName[...]]
DARef            = DataRef.DataAttributeName[.DAComponentName[...]]
DSRef（永久）    = LDName/LNName.DataSetName
DSRef（关联专用）= @DataSetName
SGCBRef          = LDName/LLN0.SGCB
GoCBRef          = LDName/LLN0.GoCBName

“/”分隔 LD 与 LN，“.”分隔后续层级。方括号表示可选，省略号表示递归，均不是实际对象名字符。可有多个子 DATA、一个顶层 DA 和多个属性分量，引用大小写须保持一致。访问 LD 本身用 LDRef，不强行补 /LN。

字段 / 规则基线约束例子 / 边界
ObjectName最多 32 个可见字符，父容器内唯一Pos 是名；LD_A/XCBR1.Pos 是引用
ObjectReference最多 255 个可见字符抽象路径不含 FC；FC 单独限定
LDName第 19 章最多 32 字符，应用特定LDevice@inst=LD0 不等于完整 LD 名；通常由 IED 名和 inst 构成，ldName 等按实际版本规则
LNName前缀 + 四字符类名 + 数字实例号；基线前缀与实例号合计≤7GO + GGIO + 1 → GOGGIO1；LLN0 为管理 LN
DataName第 19 章最多 10 字符，7-4 数据名不能把这一基线限制当作所有后续版/扩展的全规则
FCD 名称部分基线最多 29 字符，含点分隔符，不含 FC与完整 ObjectReference 长度是不同约束
名称字符A～Z、a～z、0～9、下划线/、.、@ 用于路径/作用域，不是任意局部名字符
DSRef永久路径或 @DataSetName非永久实例属于创建它的关联
控制块引用BRCB/URCB/LCB 为 LD/LN.控制块名MMS 映射 LLN0$BR$brcbRelayEna01 与抽象点路径分开
作用域第 19.3 节服务器、LD、TPAA 使用 /、LDName/、@ 标志是作用域规则，不合并为一种 DO 路径

真实例子：C_M1101X 的 MEAS 数据集成员 prefix=GO、lnClass=GGIO、lnInst=1、doName=AnIn1、daName=mag.f、fc=MX。按通常命名得到 C_M1101XMEAS/GOGGIO1.AnIn1.mag.f，FC=MX 单独保留。MMS 可能映射为域名及带 $ 的项目名，不给 ACSI 点路径夹入 $MX$。

原文表 42 将 LOG 引用写为 LDName/LDName，与同文 LOG 属性及工程表达不宜机械拼接。本文保留来源差异提示；实际 LogName/LogRef 按采用的 SCSM 和设备目录核对，LogControl@name 不能直接代替日志存储实例名。

4. ServiceError：全部十二项基础错误

属性名 ServiceError，类型 ENUMERATED，用于否定响应。下列场景为原创解释，不表示每项只有一种原因。表 5 没有给出跨映射通用数字编码，不能自行分配 MMS 错误码。

枚举中文典型解释
instance-not-available实例不可用对象不存在或当前视窗不可用
instance-in-use实例正在使用所需空闲对象已在使用
access-violation访问违例客户不具有访问资格
access-not-allowed-in-current-state当前状态不允许访问例如使能时限制配置写入
parameter-value-inappropriate参数值不合适单个参数不满足要求
parameter-value-inconsistent参数值不一致参数间或与配置不一致
class-not-supported类不支持服务器不支持请求的类
instance-locked-by-other-client被其他客户锁定关联保留或选择冲突
control-must-be-selected控制必须先选择SBO 未获得有效选择资格
type-conflict类型冲突值类型与定义不同
failed-due-to-communications-constraint通信约束导致失败通信资源或传输限制
failed-due-to-server-constraint服务器约束导致失败服务器资源或实现限制

第 17 章 AddCause 另提供控制原因；SCSM 及其应用层也可以扩展表示。基础服务错误、控制原因与协议实际字段分别核对。本次错误不会由 SCD 配置文件记录。

5. PACKED-LIST：整体的有序分量

采用处定义有序类型分量，再映射为高效编码。原文规定不能通过该类型单独访问其中某一值；理解上可拆解，访问粒度按服务/映射确定。它不是 ZIP 压缩算法。位数和位序由采用处及映射定义。

采用处逻辑组成配置 / 运行表现
TriggerConditionsdchg、qchg、dupd、integrity、GITrgOps 命名 BOOLEAN 属性
TimeQuality闰秒、时钟故障、未同步、准确度时标内部品质，通常不拆成 SCD 标签
Checksynchrocheck、interlock-check控制请求参数，非 SCD 命令
OptFlds报告/采样模型规定的字段选择OptFields / SmvOpts 为配置，不证明相同线上位序

6. TimeStamp：语法、精度和时间品质

TimeStamp 使用 1970-01-01 00:00:00 UTC 纪元。原表 7 写 SecondSinceEpoch=INT32、FractionOfSecond=INT24；语义是非负纪元秒和 24 位二进制小数，不可按普通有符号整数解释分数最高位。线上无符号表示、宽度、位布局和闰秒处理由映射确定。

分量原文类型 / 存在值域与含义例子
SecondSinceEpochINT32 / M；原表 0～MAX整秒数；MAX 按采用规范/映射核对1 为纪元后 1 秒
FractionOfSecondINT24 / MΣ bᵢ×2⁻⁽ⁱ⁺¹⁾，i=0..23；0≤分数<11000…0 → 0.5 s；8388608/2²⁴
TimeQualityTimeQuality / M产生时标的时源品质时间可读不代表已同步
教学演算：SecondSinceEpoch=1，FractionOfSecond=0.5
UTC 显示：1970-01-01T00:00:01.500Z
北京显示可转换为 UTC+08:00，原时标仍使用 UTC 语义。
24 位分数最小步长：2^-24 s ≈ 59.6046 ns。

约 60 ns 是表示分辨率，不是 IED 对 UTC 的实际误差，也不是采样周期。增加显示小数位不会提高时源准确度。

7. EntryID 与 EntryTime

字段 / 类型用途样式与边界SCD 关系
EntryID / 字节串BRCB 恢复、LOG 增量查询教学 01 A2 00 10；保存原始字节，不推断为时间或序号；长度/语义由 SCSM 定义OptFields@entryID 为字段选项，不保存每个条目 ID
EntryTime / SCSM 日期时间类型报告/日志条目进入缓冲或存储的时间人可读 2026-10-03T00:00:00Z 只是教学显示，不指定线上语法TimeOfEntry/TimeOfLog 不等于控制块 XML 静态属性
DATA.t / TimeStamp按 CDC 定义的数据时刻事件时间和条目时间可能不同DOType/DA@name=t、bType=Timestamp

事件可有相同时间值，时钟也可能失步。恢复时不能用自己构造的时间代替服务器 EntryID；循环日志还须核对最旧/最新条目、标识和时间范围。

8. TriggerConditions、TrgOp 与 intgPd

条件类型 / 值域含义 / 使用SCD 表现
data-change / dchgBOOLEAN值按 CDC 规则变化；测量死区可能抑制微小变化DA@dchg + TrgOps@dchg

data-update / dupdBOOLEAN数据刷新，值不必变化DA@dupd + TrgOps@dupd
integrityBOOLEAN控制块周期启动完整数据集报告/记录TrgOps@period + intgPd

TrgOp 是 DA 的事件特征，TrgOps 是控制块采用的触发。报告还要求对象属于数据集、控制块运行条件成立且报告使能。GI 和 integrity 不依赖单个 DA 的 dchg 特征。
