综合练习：从一条馈线读到工程证据

一个原创场景，串起一次设备、测量、保护、模型、服务与排查。

教学场景与已知条件

虚构馈线 Learn-F01：单母线，线电压 10 kV、50 Hz；负荷在本算例中对称且正弦，电流 180 A、功率因数 0.9（滞后）。常规 CT 比为 600/1 A。功能说明要求采集电流、提供过流保护、跳开指定断路器，并把位置和动作事件送至 HMI。

这里没有整定值、完整 SCD 或真实地址。所有标识、数字和假设均为原创、脱敏教学用途，不等同于可投产工程。你要形成“已知、可计算、需证据、不能推断”四类记录。

第 1 步：从物理回路到测点

先画出母线、断路器、CT 和负荷的关系，标明 CT 位置、极性、相别与参考方向。若采用 MU，补充采样通道与数据输出关系；若直接模拟接入 IED，不应凭空增加 MU。

计算本例的二次电流、S、P 和恒定 1 小时电能 · 展开参考答案

理想 CT 线性范围内，I二次=180/600=0.3 A。S=√3×10 kV×180 A≈3.118 MVA；P=0.9S≈2.806 MW；恒定 1 h 时 E≈2.806 MWh。工程中还需核对测量误差、波形、方向和量的基准。

如果应用显示 0.3 A，先确认一次/二次语境；如果显示 180 A，不要再乘 600。需要的证据是铭牌、档位、装置缩放与点表，不能只看单位。

第 2 步：写出功能与对象候选

需求可能的标准对象必须补充的证据
电流测量MMXU.A 的相分量，按实际 CDC 追踪 cVal / q / t 等LNodeType → DOType → DAType；单位/倍率、相别、一次量基准与通道映射。
延时过流保护PTOC 的 Str、Op 等功能说明、定值和投退；仅有 LN 不证明阈值、配合及出口。
跳闸整合PTRC.Tr 等实际逻辑与出口绑定；可能在装置内，也可能跨 IED。
断路器位置XCBR.Pos 的状态、品质、时标一次设备绑定、双点编码、辅助接点和反馈接线。
控制CSWI / XCBR 相关控制对象实际控制对象与 ctlModel、权限和闭锁规则，不强制固定实现。

名称仅为语义候选，实例可有前缀和其他部署。不要从 LearnIED、MAC 或 APPID 倒推线路功能。

第 3 步：为数据交换选择适用服务

交换内容候选机制检查证据
采样序列（若数字化过程层）SVSampledValueControl → DataSet / FCDA → SMV，订阅输入、采样配置和时间同步。
跨设备快速跳闸 / 闭锁（若设计采用）GOOSEGSEControl → DataSet → GSE，接收 Inputs / ExtRef 及装置内逻辑。
HMI 位置、测量、事件MMS 报告等ReportControl、DataSet、触发、缓冲与客户端配置；不是所有显示都逐点轮询。
操作员命令映射后的控制服务ctlModel、选择/操作、权限与终止结果；实际位置仍从反馈对象核对。

相同业务需求可以有不同设备与通信实现；教学链中的箭头不是强制网络架构。

第 5 步：对三个现象提出下一条证据

保护动作已上送 HMI，但断路器仍显示合位 · 展开参考答案

先核对源时间和品质是否可比、反馈是否新鲜，再查动作→PTRC/出口→硬接点或 GOOSE/订阅→执行回路→机构→辅助接点的链。HMI 有动作事件只证明该观察路径，不能证明跳闸输出已执行。

三相测量为 0，但品质无效且连接刚断开 · 展开参考答案

结论应是测量失效/未知，不能认定无电流或停电。保存最后有效值、失效状态与时间，核对接收链、数据源和测量链。

SCD 能导入，是否完成了这个馈线的验收？ · 展开参考答案

导入最多说明该工具接受了文件；还要分别检查模式、引用、语义、设备能力、交付版本和现场功能。必须写明本次究竟通过了哪一层检查。

完成标志与继续练习

  • 能从一次测量点追到一个模型对象，解释数值、单位、方向、q 和 t。
  • 能区分保护起动、动作、出口、设备反馈，以及控制服务阶段。
  • 能说出每个引用的目标以及缺失证据，不以命名推断实际绑定。
  • 能把异常分到物理测量、逻辑、配置、通信、执行与应用显示各层。
