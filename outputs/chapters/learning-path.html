从编程到电气：零基础学习路线

先认识电网和设备，再理解信号、功能、信息模型与工程配置。

读者起点与学习方式

你已经熟悉类型系统、引用、网络和状态机，可以快速理解 XML 和对象层级；更需要补的是“数据描述了哪一种物理现象，以及系统为什么这样动作”。先完成下面 8 阶段，再把 LN/CDC 全表作为字典使用。每一步的完成标志比阅读时长更有用。

首次阅读从电气量与三相电开始。已熟悉电气基础者可直接进入第 5 阶段；正在查对象时用首页术语检索与标准文库。

按前置知识推进的 8 阶段

  1. 01

    先建立电气量的直觉

    知道设备承载什么

    电路、三相电与功率

    完成标志：能解释 10 kV、200 A、kW 与 kWh 分别是什么，说明公式的条件。

  2. 02

    看懂一次系统

    先看能量路径，再看信息路径

    一次接线与设备 → 一次系统与设备角色

    完成标志：能区分断路器、隔离开关、接地开关、CT、VT 和变压器；沿图定位间隔。

  3. 03

    理解测量与保护

    物理量如何变成数据，故障如何被切除

    互感器、采样与信号 → 保护、控制与跳闸闭环 → 保护 IED 功能范围

    完成标志：能追踪采样→判据→出口→反馈，解释通信成功与设备动作的区别。

  4. 04

    放回变电站自动化架构

    把设备和功能放进层级

    间隔与自动化层级 → 三层两网 → 易混概念对照 → ACSI 抽象接口

    完成标志：能解释一次/二次、站控/间隔/过程层，以及网络与逻辑层级的区别。

  5. 05

    进入标准信息模型

    从领域对象到类型与实例

    IED → LN → DO → DA → 属性和值 → 品质、时间与公用类型 → 控制和输入

    完成标志：能沿一个 DO 找到 CDC、FC、q/t、单位与枚举来源。

  6. 06

    阅读工程配置

    用 XML 引用形成可核对证据

    工程交换文件 → 十分钟读懂 SCD → 引用追踪工具箱 → 最小 XML 示例 → 数据集与控制块

    完成标志：能按实例和类型两个方向追踪 FCDA、控制块和订阅，识别缺失证据。

  7. 07

    学习通信与软件语义

    模型、服务与传输分别核对

    通信与过程层 → ACSI 服务 → 服务映射 → 静态协议字段 → 开发人员的数据契约

    完成标志：能分清 SV、GOOSE、Report 与控制；正确处理质量、时间、重复与失效。

  8. 08

    完成静态工程练习

    把所学串成证据链

    馈线综合练习与答案 → 工程证据核查 → 变更与交付 → 分层排障 → 安全与测试边界

    完成标志：能列出配置能证明什么、还缺什么；不以名称或报文到达代替业务和现场证据。

这次补齐了哪些知识缺口

原有基础需要补齐的桥梁现在的入口
LN、CDC 和标准数据全表电压、电流、三相、功率与电能的物理含义电气基础
Substation / Bay 与设备缩写一次接线、母线、端子/连接节点与设备功能一次接线
SV、MMXU、品质和时标CT/VT 变比、方向、采样、测量窗口与事件时间测量链
PTOC / PTRC / XCBR 和控制模型故障、选择性、出口、断路器机构与反馈闭环保护控制基础
协议字段与服务清单缓存失效、重复事件、品质、跨设备时间和控制结果开发数据契约
分散的专题和参考工程证据一个教学馈线贯穿物理、对象、服务与排查综合练习

后续进阶可研究短路计算、接地系统与零序网络、变压器接线组别和差动补偿、保护整定配合、IEC 62351 安全工程及项目试验规范。本路线只介绍理解 IEC 61850 所需的前置概念，不把这些进阶专题声称为已完整覆盖。
