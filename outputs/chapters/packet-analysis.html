1. 先回答：为什么以 MMS、GOOSE、SV 为主线？

在常见变电站工程中，以三类核心业务通信学习报文是合理的。IEC 61850 是覆盖模型、服务、工程配置与映射的标准体系；MMS、GOOSE、SV 是其中常见通信主线，不能代替整个体系。本文限定传统站内以太网映射，不把其他场景强行归入这三类。

主线解决的问题 / 原创场景承载与交互先找什么
MMS监控客户端读取开关位置、接收遥信/遥测报告；控制和定值的服务映射TCP/IP上ISO关联；请求/响应和未确认报告同一关联、服务、invokeID、domain/item名
GOOSEIED向订阅端发布开关状态、保护事件或联闭锁信息传统8-1为Ethernet二层组播，无TCP确认；用重传维持状态0x88B8、gocbRef、datSet、stNum/sqNum
SV / SMV合并单元向保护/测控提供电流、电压瞬时采样传统9-2为Ethernet二层发布；按配置周期连续采样0x88BA、svID、ASDU、smpCnt、seqData

GOOSE = Generic Object Oriented Substation Event（面向通用对象的变电站事件）；SV = Sampled Values（采样值），SCL 中常用 SMV 命名。应用场景可能重叠：位置既能由 MMS 读/报告，也能被配置为 GOOSE；瞬时采样 SV 与 MMS 的 RMS/相量遥测不可混同。

还要了解 Ethernet、可选 802.1Q VLAN、ARP、IPv4/IPv6、TCP 分段重组、TPKT/COTP、关联协商、ASN.1/BER、时间品质和 SNTP/PTP、PRP/HSR 冗余及捕获截断。IEC 61850-8-2、可路由事件/采样映射等属于进一步范围；抓到其他流量不能一概当作异常。

3. 固定的六步分析法

  1. 确定用途：一次物理量/状态是什么，谁发布、谁消费，当前证据能说明什么。
  2. 找配置：IED / AP / LD / LN / DO / DA，沿类型模板确认 FC、基本类型、单位。
  3. 找集合与控制：GOOSE/SV 看 DataSet 和控制块；MMS 单变量 Read 可直接访问，报告再看 RCB / DataSet。
  4. 读结构：先帧长与协议层，再服务/APDU/ASDU，按 Tag/Length 确定 Value 边界。
  5. 还原值：按 FCDA 顺序和类型解释，记录品质、时标、计数、配置版本和歧义。
  6. 反查与变化：回到 SCD 验证发布源/订阅证据，比较事件与重传、采样相邻时刻；证据不足保留未知。

SCD → IED / AP → LD / LN → DO / DA → DataSet / Control Block → Communication → 报文 → 字段 → 信号；MMS 的直接 Read 在 DO/DA 后进入变量访问服务，不必绕过一个控制块。

5. 从 Hex 到字段，先认识长度

84 02 06 80 在本例 MMS Data / GOOSE Data 上下文中是 BIT STRING：Tag=84，Length=02（Value占2字节），Value=06 80。06 表示末字节6个未用位，有效位10表示 Dbpos on。它不能被解读为整数0x0680，也不能脱离上下文把所有84都叫位串：GOOSE顶层84是时间字段。

BER 短长度 7F 表示127；长长度 81 80 表示后续1字节给出128；82 01 00 表示256。父容器长度只统计其Value，子字段的Tag/Length也在父Value内。长度阈值变化会让后续偏移整体移动，因此禁止把示例偏移当成通用解析规则。

层次名：PDU = Protocol Data Unit；APDU = Application Protocol Data Unit；ASDU = Application Service Data Unit。SV 的 seqData 是八位串，通道值不各带一个 BER Tag；MMS/GOOSE 的 Data 选择则包含类型标签。

来源、版次与适用范围

版次与来源边界：以项目既有早期 IEC 61850-8-1 中文资料的传统 MMS/GOOSE 映射为起点，并参照公开解码器 ASN.1 定义核对结构；SV 采用明确声明的 9-2 八通道 INT32/Quality 教学布局。它不是跨版次唯一实现，也不宣称完整符合 9-2LE 或 IEC 61869-9。本地9-2为DL/T 860.92—2006扫描件，本次视觉复核PDF第16～17页（印刷第12～13页）表13/14的容器及基础类型；早期smpSynch为BOOLEAN，本例按较新版公开解码定义的0/1/2枚举解释，1表示local，不能混用。7-2扫描件未逐条核验。公开解码器是交叉核对资料，不能替代适用版次标准。

职责：IEC 61850-6 管配置与交换；7-2 定义 ACSI（Abstract Communication Service Interface，抽象通信服务接口）；7-3 定义 CDC（Common Data Class，公用数据类）；7-4 定义 LN（Logical Node，逻辑节点）及数据对象；8-1 将服务映射到 MMS/传统 GOOSE；9-2 定义 SV 以太网映射。ISO 9506 定义 MMS（Manufacturing Message Specification，制造报文规范）；ASN.1（Abstract Syntax Notation One）描述结构；BER（Basic Encoding Rules）将结构编码为字节。IEC 62351 安全扩展不在本例内。
