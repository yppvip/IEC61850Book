1. 表格范围与读法

本表参照“变电站通信网络和系统 第 2 部分：术语”第 3 章的缩写主题，优先收录当前离线知识库和 SCD 阅读中已经涉及、且工程上常需辨认的术语。它是原创释义表，不逐字复现标准；“功能”描述术语在 IEC 61850 模型、工程文件或通信中的作用，不能替代设备能力、项目设计或现场结论。

版本提示：本次已按所给第 7-2 部分补充 AA、报告、定值、公共类型和触发相关条目。届时可按“标准条目 / 当前收录 / 版本差异”逐项核对，避免将不同版次或厂商扩展混写为标准必选项。

2. 缩写总表

缩写英文全拼中文名功能
APAccess Point接入点IED 对外提供通信服务的入口；在 SCD 中与 ConnectedAP 的 apName 建立对应。
BDABasic Data Attribute基本数据属性结构化 DA 内继续展开的基本成员，用于定位复合数据的具体组成。
CIDConfigured IED Description已配置 IED 描述文件面向单台 IED 下装或使用的配置文件；其生成、导入和适用范围取决于工程工具及设备流程。
DAData Attribute数据属性DO 内表达状态值、质量、时标、控制或设置等内容的属性；其用途通常由 FC 区分。
DataSetData Set数据集按顺序组织 FCD/FCDA 成员，供报告、GOOSE 或 SV 等控制块引用。
DOData Object数据对象LN 内表达一类功能数据的对象；其内部 DA/SDO 结构可沿类型模板追溯。
GOOSEGeneric Object Oriented Substation Event通用面向变电站事件对象以发布订阅方式快速传递 DataSet 中的事件/状态信息，常用于跳闸、闭锁、联锁等。
GSEGeneric Substation Event通用变电站事件在 SCL 通信配置中承载 GOOSE 网络侧关联信息的概念/元素；须与发布控制块、地址和订阅整体核对。
ICDIED Capability DescriptionIED 能力描述文件描述 IED 模型和能力的工程交换文件，是系统配置与能力核对的重要输入。
IEDIntelligent Electronic Device智能电子设备IEC 61850 的设备模型实体；保护、测控、MU、智能终端和网关均可能作为 IED 出现。
LDLogical Device逻辑设备IED 服务器内组织 LN0 和 LN 的逻辑容器，在 SCL 中通常对应 LDevice。
LNLogical Node逻辑节点按功能组织标准数据和服务的模型单元，如 PTOC、XCBR、MMXU；不等同于一台物理设备。
LN0Logical Node Zero逻辑节点零实例逻辑设备的公共 LN 实例，常承载 DataSet、报告、GOOSE/SV 控制块等公共功能。
MMSManufacturing Message Specification制造报文规范常用于 IEC 61850 客户端/服务器通信映射，支撑读写、报告、控制等服务。
MUMerging Unit合并单元把互感器二次量采样数字化并发布采样值的典型过程层 IED 角色。
RCBReport Control Block报告控制块控制报告服务并引用 DataSet；触发选项、缓冲和可选字段需结合 IED 服务能力理解。
SCDSubstation Configuration Description变电站配置描述文件汇集一次系统、IED、通信网络和数据类型模板的全站工程配置文件。
SVSampled Values采样值以发布订阅方式传输采样数据；接收侧须按 DataSet 顺序、通道和同步信息解释。
SMVSampled Measured Values采样测量值工程中常与 SV 并用以指采样值通信/报文；具体命名以采用版次、SCL 元素和设备资料为准。
VLANVirtual Local Area Network虚拟局域网二层网络隔离与优先级规划相关技术；在工程中结合 VLAN-ID、优先级、交换机和网络方案使用。
AAApplication Association应用关联关联模型：通信双方及其访问上下文；包括 TPAA、MCAA。 详解
ACSIAbstract Communication Service Interface抽象通信服务接口接口体系：定义对象、服务及行为；描述功能用 ACSI，描述线上编码进入 SCSM。 详解
BRCBBuffered Report Control Block缓存报告控制块模型类：按触发组织并缓存报告事件；恢复时核对 EntryID、溢出与保留范围。 详解
CDCCommon Data Class公用数据类数据类：规定共用属性结构，如 DPC、SPS、MV；SCD DOType@cdc 表达类别。 详解
DATypeData Attribute Type数据属性类型类型名：ACSI 泛指属性类型；SCL DAType/BDA 描述结构属性，叶子用 bType。 详解
DataRefData Reference数据引用属性名：DATA 完整路径，如 C_G1101XLD0/LLN0.FunEna1；没有同名 SCL 标签。 详解
dchgData Change数据变化触发选项：值按 CDC 规则变化时触发，测量还需考虑死区；DA 特征和控制块采用选项分层。 详解
dupdData Update数据刷新触发选项：属性刷新可触发，值不必不同；不等于周期完整性报告。 详解
FCFunctional Constraint功能约束访问分类：按用途筛选 DA，如 ST、MX、CO、SV、SG、SE；不等于操作授权。 详解
FCDFunctionally Constrained Data功能约束数据引用形式：DO 与 FC 的组合，选择此 DO 在该 FC 下的属性集合；FCDA 省略 daName 可表达 FCD。 详解
FCDAFunctionally Constrained Data Attribute功能约束数据属性引用形式 / XML 元素：属性与 FC 的组合；SCL FCDA 也能表达 FCD，按 doName/daName/fc 区分。 详解
GIGeneral Interrogation总召唤运行命令：客户请求当前数据集完整快照；TrgOps.gi 是选项，运行 GI=true 才是启动。 详解
intgPdIntegrity Period完整性周期属性名：单位 ms；ACSI 通常写 IntgPd，XML 写 intgPd；0 不产生周期完整性报告。 详解
LCBLog Control Block日志控制块模型类：决定哪些数据按何种触发写入 LOG；LogControl 是配置，不包含历史条目。 详解
qchgQuality Change品质变化触发选项：品质变化可触发，即使数值不变；DA@qchg 与 TrgOps@qchg 分层。 详解
SBOSelect Before Operate操作前选择控制模型：先选择再操作；普通安全用 Select，增强安全用 SelectWithValue，并受超时约束。 详解
SCLSubstation Configuration Language变电站配置语言工程语言：XML 工程交换语言；SCD 是文件类型，服务请求和响应不写成 SCD 标签。 详解
SGSetting Group定值组参数集合 / FC：共同切换的一组参数；FC=SG 为激活视图，FC=SE 为编辑视图。 详解
SGCBSetting Group Control Block定值组控制块模型类：管理组数、激活、编辑和确认；LLN0/SettingControl 表达工程配置。 详解
TrgOpTrigger Option触发选项属性特征：属性事件能力；控制块 TrgOps 选择采用哪些事件；DA 的 dchg 不证明报告已使能。 详解
URCBUnbuffered Report Control Block非缓存报告控制块模型类：连接期间尽力报告；不按 BRCB 方式补送断线期间事件。 详解
TPAATwo Party Application Association双边应用关联模型类：双向、面向连接；Associate 建立，Release 正常释放，Abort 异常中止。 详解
MCAAMulticast Application Association多路广播应用关联模型类：发布者向一个或多个订户单向发送无确认信息；不逐个订户执行 Associate。 详解
SCSMSpecific Communication Service Mapping特定通信服务映射映射规范：将抽象类和服务映射到具体寻址、协议与编码，如 8-1、9-2。 详解
EntryIDEntry Identifier条目标识符公共类型：报告恢复和日志查询使用的不透明字节串；不是业务编号或时间。 详解
EntryTimeEntry Time条目时间公共类型：报告、日志与通信子系统的条目相关时间；表示由 SCSM 定义。 详解
TimeStampTime Stamp时标公共类型：由纪元秒、秒的小数、时间品质组成；可表示分辨率不证明设备准确度。 详解
PACKED-LISTPacked List压缩表公共类型：有序分量的紧凑编码，不能通过该类型独立访问分量；不是文件压缩。 详解

3. 继续阅读
