数据模型 · 第 7-1 部分关联专题

公共 LN 信息、控制模型与输入模型

理解配置如何影响输入处理、状态输出和控制条件，同时保留本地逻辑边界。

阅读位置与来源边界

上级：第 7-1 部分：原理与模型。按“概念 → 对象与属性 → SCD 证据 → 使用边界”阅读；本页是原创中文导读，不是标准原文或可投产配置。

本次基线为所给 IEC 61850:2003/2004 对应中文资料；参考 SCD 的根元素声明 version="2007"、revision="B"、release="4"。版本差异、工程实例和教学示例分别标注。XML 配置值不等于设备当前运行值。

1. 逻辑节点的信息组成

LN 以功能组织数据。每个 LN/LN0 通过 lnType 指向 LNodeType；DO 的 type 指向 DOType；DA 的 Struct/Enum 再指向 DAType/EnumType。LLN0（Logical Node Zero）承载 LD 的公共信息和部分服务控制，LPHD（Physical Device Information）描述物理设备；两者不互相替代。

信息类别概念常见 DO / CDC缩写/术语解释
公共逻辑节点信息与具体保护或测量功能无关的模式、行为、健康与铭牌Mod、Beh、Health、NamPlt；Loc、EEHealth、EEName、OpCnt、OpCntRs、OpTmh 等按 LN 表Mod Mode；Beh Behaviour；NamPlt Name Plate；EE External Equipment；OpCnt Operation Counter；OpTmh Operation Time Hours
状态信息由过程/功能产生的状态和事件，通常 STPos/stVal；Str/ACD；Op/ACT；BlkOpn、BlkCls 等按对象定义Str Start；Op Operate/Operation；Blk Block；Pos Position
定值决定功能如何计算、判断或运行的参数，变化较少StrVal、OpDlTmms、曲线和系数；ASG/ING/SPG/CURVEDl Delay；Tm Time；ms millisecond；StrVal 启动定值
测量值过程采样或计算结果，通常 MXA、PhV、PPV、Hz、W、VAr、VA、PF；WYE/DEL/MV 等PhV Phase Voltage；PPV Phase-to-Phase Voltage；PF Power Factor
控制可请求改变目标状态/设点的对象Pos/DPC，部分复位/投退点/SPC，设点/APCCO Control；SBO Select Before Operate
计量一段时间累积或积分结果MMTR 中电能等；BCRMMTR Metering；计量值不等于即时测量值

这些分类是阅读功能表的分组，SCD 并不必然有 <Status>、<Measurement>、<Control> 三个 XML 文件夹。真正的组织依据是 LN 的 DO、CDC、DA.fc 和类型链；DA 的配置值还在 DOI/SDI/DAI/Val 中。

2. 什么是公共信息

公共对象功能与运行/配置的关系
Mod请求/设定工作模式可控信息；取值语义由 LN 类型决定
Beh实际生效的行为状态信息；受本 LN 和上层 LD 等行为影响，不能简单等于 Mod
HealthLN 功能健康状态常见 OK/Warning/Alarm 语义，实际编码查类型
NamPltLN 铭牌LPL；供应商、软件版本、描述、命名空间等
Loc本地控制状态是否本地操作；存在范围按 LN 表
EEHealth / EEName外部设备健康/铭牌对应关联外部设备，不是任意厂商名称匹配
OpCnt / OpCntRs / OpTmh操作计数 / 可复位操作计数 / 运行小时统计对象，复位服务与权限须核对
LPHD.PhyName / PhyHealth / Proxy物理设备铭牌 / 健康 / 代理标记LPHD 不按其他功能 LN 的公共信息规则机械复制
LLN0 的公共数据与控制块整个 LD 的共用信息、服务配置LD 范围；GOOSE/SV/定值组控制配置常位于 LN0

常见模式为 on、blocked、test、test/blocked、off。参考 SCD 的相关枚举常编码 1～5，须先沿具体 Mod/Beh 类型核对。blocked、test 等行为对上层服务和本地功能的作用不能由英文单词自行推断；尤其 Test 字段、Quality.test 和 Mod=test 属于不同位置。

Mod/Beh 常见码（参考枚举）英文含义与解释边界
1on投入正常功能；Mod 是请求，Beh 是实际行为
2blocked处于闭锁行为；具体输出、报告和本地功能作用按适用模型
3test测试行为；不得与命令 Test 或单个 q.test 混作一个位置
4test/blocked测试并闭锁的组合行为；应用接受策略另核对
5off退出相应功能；不等于设备断电或网络必然断开
Health 常见码英文含义
1OK相关功能未报告健康告警
2Warning健康警告，需结合具体诊断信息
3Alarm健康告警，不能仅凭此码确定故障部件

以上编码依本次参考枚举列出；完整功能影响仍由采用版次、上层 LD 行为和设备实现共同决定。Mod=on 不保证所有局部闭锁已解除，Health=OK 也不是现场功能验收结论。

3. 控制模型：概念、功能和全部 ctlModel 值

控制模型管理一项控制请求的整个生命周期：是否先选择、谁持有选择、请求何时执行、如何检查条件、是否监视反馈以及怎样报告最终结果。常规/增强“安全”描述的是控制流程可靠性，不能等同于加密、认证或网络安全等级。

编码（参考 SCD 已核对）英文枚举中文行为
0status-only仅状态只监視状态，不提供可执行控制
1direct-with-normal-security常规安全直接控制Operate；不先选择，控制对象不按增强模型监视最终状态
2sbo-with-normal-security常规安全操作前选择Select → Operate；超时/Cancel 释放选择
3direct-with-enhanced-security增强安全直接控制Operate → 状态监视 → CommandTermination
4sbo-with-enhanced-security增强安全操作前选择SelectWithValue → Operate → 状态监视 → CommandTermination
配置/参数可取值或结构用法
sboClass0 operate-once；1 operate-many（参考枚举）单次用后释放 / 选择超时前保持资格
sboTimeoutINT32U，ms选择资格时限；机械到位超时应另读设备参数
Oper.ctlVal按 CDC；DPC 为 BOOLEAN目标分/合，不是直接写四态反馈
originorCat + orIdent来源类别与标识
ctlNumINT8U，0～255控制序列号
TTimestamp请求相关时标，映射参数
TestBOOLEAN请求的测试标志，解释受设备测试策略约束
Checksynchrocheck 与 interlock-check 位请求适用的检查；不编码完整判据
operTm / operTimTimestamp，若支持时间激活预定执行时刻；名称按资料/类型声明
Cancel结构/控制服务取消选择或等待中的请求

肯定 Operate 响应是请求阶段的结果；最终反馈与命令终止是另外的证据。SBO（Select Before Operate）不是将所有条件“永久锁定”，执行时仍可能需要重新检查。

4. 在 SCD 中如何体现和解读控制关系

<!-- 原创脱敏片段：实际配置值须由对应模板提供 ctlModel/sboClass 定义 -->
<LN lnClass="XCBR" inst="1" prefix="" lnType="T_XCBR">
  <DOI name="Pos">
    <DAI name="ctlModel"><Val>sbo-with-enhanced-security</Val></DAI>
    <DAI name="sboTimeout"><Val>5000</Val></DAI>
    <DAI name="sboClass"><Val>operate-once</Val></DAI>
  </DOI>
</LN>

沿 LN.lnType → LNodeType.DO[name=Pos].type → DOType[cdc=DPC] 找 ctlModel、stVal、Oper、SBOw、Cancel。若 Oper 为 Struct，继续到 DAType/BDA，查 ctlVal、Check、T 等。实例 DOI/DAI/Val 配置值会影响参数，但未写 Val 不能当作值为零：可能由模板默认值、设备配置或实现规则确定。

CSWI 的控制对象、CILO 的允许条件、XCBR 的位置/执行模型可共同构成开关控制功能。SCD 能给出对象和部分输入映射；完整执行链还可能包含本地逻辑、开出映射、终端回路与反馈接线。不能仅因这三类 LN 同时存在，就认定它们已经形成正确控制闭环。

6. 输入模型：从采集到可交换信息

7-1 输入模型是采集与处理模型：现场信号调理/数字化后，经过取代、更新闭锁、品质处理，再形成即时值、过滤值、范围状态和事件。SCL 的 Inputs/ExtRef 则描述通信来源引用：它是配置结构，不能替代整条采集链或 ADC（Analogue-to-Digital Converter，模数转换器）特性。

二进制输入还可能需要去抖、振荡检测和瞬变处理；其参数是否标准化、是否在 SCD 中开放，由 LN/CDC、设备与工程配置共同决定。数据处理算法不一定能从一个 DA 名复原。

原创例子：过程量 min=0 A、max=1000 A，db=1000 表示 1000×0.001%=1%，按差值阈值演算为 10 A。若当前保留 mag=100 A，instMag=105 A，差值未超过阈值；instMag=112 A 时可能更新 mag 并产生变化事件。7-3 允许具有可比效果的死区算法，具体时序仍需实现说明。

另一个演算：mag.i=12345、scaleFactor=0.01、offset=0，得到 mag.f=123.45；若 SIUnit=A、multiplier=0，表示 123.45 A。若倍率或变比不同则含义改变。SCD 缺少一次/二次量语义时，不能自动乘 CT 变比。

9. 定值组和输入订阅的组织方法

SettingControl 位于 LN0，配置 numOfSGs、actSG 等；支持定值组的 DA 以 SG/SE 视图读写，不支持组的简单定值常为 SP。编辑组、确认编辑、选择激活组是分开的服务步骤。SCD 的 Val 可带 sGroup 表达某组配置，但不能由单个数值推断当前生效组。

Inputs 位于接收方 LN/LN0，ExtRef 指向外部 IED/LD/LN/DO/DA，intAddr 是接收设备的内部映射标识。参考文件的 ExtRef 没有声明 serviceType/srcCBName 等源控制块定位字段，因此需要反查发布数据集和控制块建立候选链，并保留多义性。
