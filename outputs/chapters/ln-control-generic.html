继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述

GrWrnSPSO—由配置指定的一组预告汇总，TRUE 表示该组预告。
AlmLstOvSPSO—TRUE指示告警列表溢出

CILO：联锁

Interlocking；只表达联锁条件许可 EnaOpn/EnaCls。条件许可、设备闭锁、控制服务、物理动作是不同环节。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
EnaOpnSPSM—联锁功能确定该数据状态，为TRUE时表示允许装置分闸
EnaClsSPSM—联锁功能确定该数据状态，为TRUE时表示允许装置合闸

CPOW：定点分合

Point on wave switching；在交流波形选定时刻执行分合，用于控制开断/合闸过程；须结合开关机构延时，不能把逻辑时刻当成实际触头时刻。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
TmExcSPSM—TRUE 表示 CPOW 允许的最大时间差已超出。
StrPOWSPSO—为TRUE时表示由CSWI或RREC请求启动CPOW（如通过选择）
OpOpnACTOT开关分闸动作信息；它不等于 Pos 已反馈分位。
OpClsACTOT开关合闸动作信息；控制模型服务不适用时原文允许用相应事件状态传送，须持续足够长供检出。
MaxDlTmmsINGO—允许的操作时刻差，涉及请求/期望操作与实际完成之间的时段，单位 ms。

原文：5.6，PDF 47；工程观察：0 个实例。本工程未出现，不能借其他类同名数据充当此类证据。

CSWI：开关控制器

Switch controller；代表开关控制功能，Pos 用 DPC；可按相提供 PosA/B/C。联锁检查由 CILO 表达，过程设备由 XCBR/XSWI 表达。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
LocSPSO—就地/远方位置状态；TRUE 为就地，FALSE 为远方。LD 与 LN 冲突时就地主导。
OpCntRsINCO—可复位逻辑节点动作计数
PosDPCM—设备位置状态与可选控制命令；手动开关仅表示状态，命令是否存在按 CDC/实例核对。
PosADPCO—在A相可能单独操作处，该数据用于分合操作
PosBDPCO—在B相可能单独操作处，该数据用于分合操作
PosCDPCO—C 相独立分合的状态/控制对象。
OpOpnACTOT开关分闸动作信息；它不等于 Pos 已反馈分位。
OpClsACTOT开关合闸动作信息；控制模型服务不适用时原文允许用相应事件状态传送，须持续足够长供检出。

GAPC：通用自动过程控制

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
LocSPSO—就地/远方位置状态；TRUE 为就地，FALSE 为远方。LD 与 LN 冲突时就地主导。
OpCntRsINCO—可复位逻辑节点动作计数
SPCSOSPCO—通用单点可控状态输出

GSAL：通用安全应用

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
OpCntRsINCM—可复位逻辑节点动作计数
NumCntRsINCM—计数器复位次数
AuthFailSECM—授权失败次数
AcsCtlFailSECM—检测到访问控制失败次数

InaSECM—因未激活/不活动而终止的关联计数；结合安全监视语境。
