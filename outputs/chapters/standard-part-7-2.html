第 7-2 部分：抽象通信服务接口 ACSI

从信息对象，理解服务、配置引用和运行行为。

阅读位置与版本

上级：标准文库。按“概念 → 属性与服务 → SCD 证据 → 工程使用”阅读。

标准基线：DL/T 860.72—2004（等同 IEC 61850-7-2:2003）；参考 SCD 为 SCL 2007 B4。抽象模型、协议映射、XML 配置和设备运行值分别解释。本文为原创导读，工程摘录保留源文件关键字与名称，不是完整可投产配置。

1. 本部分解决什么问题

监控计算机读取设备数据、接收事件或提出控制请求时，需要约定“访问哪个对象、调用什么服务、结果是什么意思”。ACSI 给出这一共同约定。SERVER 是 IED 对外呈现的模型和行为，不一定是一台独立计算机；Client 是请求服务并接收通知的应用。一次设备通过传感、控制或执行装置与信息系统相连，不能把断路器直接当作网络服务器。类 Class 是共同规则，实例 Instance 是具体对象，二者不能混用。

2. 基本模型与层级

基本骨架是 SERVER → LD → LN → DATA，DA 再描述数值、品质、时标及配置等细节。DataSet 组织交换成员，控制块组织交换行为。Control 针对可控 DATA；Control Block 则管理报告、日志、定值或发布过程。

3. ACSI 类与支撑类型完整导览

下表覆盖参考正文的对象类及第 10 章属性类型结构。Control、Substitution、Time/TimeSynchronisation 是行为/服务模型，没有同名 SCL 元素。SimpleCDC、CompositeCDC 是 DATA 特例化；CompositeComponent、PrimitiveComponent 是 DAType 组成角色，具体 CDC 和属性类型在 7-3 定义。

5. 缩略语、属性名和类型名

这些名称已同步进入全局术语检索。表中区分缩略语、属性名和类型名，保留必要英文原文。

名称英文中文类别功能与用法
AAApplication Association应用关联关联模型通信双方及其访问上下文；包括 TPAA、MCAA。 详解
ACSIAbstract Communication Service Interface抽象通信服务接口接口体系定义对象、服务及行为；描述功能用 ACSI，描述线上编码进入 SCSM。 详解
BRCBBuffered Report Control Block缓存报告控制块模型类按触发组织并缓存报告事件；恢复时核对 EntryID、溢出与保留范围。 详解
CDCCommon Data Class公用数据类数据类规定共用属性结构，如 DPC、SPS、MV；SCD DOType@cdc 表达类别。 详解
DATypeData Attribute Type数据属性类型类型名ACSI 泛指属性类型；SCL DAType/BDA 描述结构属性，叶子用 bType。 详解
DataRefData Reference数据引用属性名DATA 完整路径，如 C_G1101XLD0/LLN0.FunEna1；没有同名 SCL 标签。 详解
dchgData Change数据变化触发选项值按 CDC 规则变化时触发，测量还需考虑死区；DA 特征和控制块采用选项分层。 详解
dupdData Update数据刷新触发选项属性刷新可触发，值不必不同；不等于周期完整性报告。 详解
FCFunctional Constraint功能约束访问分类按用途筛选 DA，如 ST、MX、CO、SV、SG、SE；不等于操作授权。 详解
FCDFunctionally Constrained Data功能约束数据引用形式DO 与 FC 的组合，选择此 DO 在该 FC 下的属性集合；FCDA 省略 daName 可表达 FCD。 详解
FCDAFunctionally Constrained Data Attribute功能约束数据属性引用形式 / XML 元素属性与 FC 的组合；SCL FCDA 也能表达 FCD，按 doName/daName/fc 区分。 详解
GIGeneral Interrogation总召唤运行命令客户请求当前数据集完整快照；TrgOps.gi 是选项，运行 GI=true 才是启动。 详解
intgPdIntegrity Period完整性周期属性名单位 ms；ACSI 通常写 IntgPd，XML 写 intgPd；0 不产生周期完整性报告。 详解
LCBLog Control Block日志控制块模型类决定哪些数据按何种触发写入 LOG；LogControl 是配置，不包含历史条目。 详解
qchgQuality Change品质变化触发选项品质变化可触发，即使数值不变；DA@qchg 与 TrgOps@qchg 分层。 详解
SBOSelect Before Operate操作前选择控制模型先选择再操作；普通安全用 Select，增强安全用 SelectWithValue，并受超时约束。 详解
SCLSubstation Configuration Language变电站配置语言工程语言XML 工程交换语言；SCD 是文件类型，服务请求和响应不写成 SCD 标签。 详解
SGSetting Group定值组参数集合 / FC共同切换的一组参数；FC=SG 为激活视图，FC=SE 为编辑视图。 详解
SGCBSetting Group Control Block定值组控制块模型类管理组数、激活、编辑和确认；LLN0/SettingControl 表达工程配置。 详解
TrgOpTrigger Option触发选项属性特征属性事件能力；控制块 TrgOps 选择采用哪些事件；DA 的 dchg 不证明报告已使能。 详解
URCBUnbuffered Report Control Block非缓存报告控制块模型类连接期间尽力报告；不按 BRCB 方式补送断线期间事件。 详解
TPAATwo Party Application Association双边应用关联模型类双向、面向连接；Associate 建立，Release 正常释放，Abort 异常中止。 详解
MCAAMulticast Application Association多路广播应用关联模型类发布者向一个或多个订户单向发送无确认信息；不逐个订户执行 Associate。 详解
SCSMSpecific Communication Service Mapping特定通信服务映射映射规范将抽象类和服务映射到具体寻址、协议与编码，如 8-1、9-2。 详解
EntryIDEntry Identifier条目标识符公共类型报告恢复和日志查询使用的不透明字节串；不是业务编号或时间。 详解
EntryTimeEntry Time条目时间公共类型报告、日志与通信子系统的条目相关时间；表示由 SCSM 定义。 详解
TimeStampTime Stamp时标公共类型由纪元秒、秒的小数、时间品质组成；可表示分辨率不证明设备准确度。 详解
PACKED-LISTPacked List压缩表公共类型有序分量的紧凑编码，不能通过该类型独立访问分量；不是文件压缩。 详解
