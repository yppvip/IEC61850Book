间隔、设备缩写与自动化层级

从一张单线图认识 Bay、一次设备、逻辑节点和站控/间隔/过程层。

1. 什么是间隔（Bay）

间隔是变电站一次系统中围绕某个回路或运行单元组织的局部范围，常见为线路、主变、母联、母线分段、电容器、电抗器或馈线间隔。它通常包含该回路的开关设备、互感器、连接导体以及对应的测量、保护、控制和闭锁功能。间隔是一次系统的组织概念，不等于一台 IED、一个保护屏或一个 LN。

常见类型常见一次设备/对象常见自动化功能
线路间隔断路器、隔离开关、接地开关、CT、VT、避雷器、出线。线路保护、测量、同期/重合闸、开关控制。
主变间隔主变、套管 CT、各侧断路器/隔离开关、分接头相关设备。差动保护、后备保护、测量、调压与控制。
母联/分段间隔母联或分段断路器、两侧隔离开关、CT。母线运行方式切换、闭锁、测量和控制。
电容器/电抗器间隔断路器、隔离开关、CT/VT、电容器组或电抗器。无功控制、保护、测量、投切。
虚拟间隔：工程中可为跨多个物理间隔的功能建立逻辑/功能组织，例如母线闭锁或站域控制。它帮助表达功能归属，但不能仅凭名称推定为一个实际新增的一次回路或柜体。

2. 怎样在电气单线图上查看一个间隔

单线图用一条线概略表示三相一次回路。先沿母线或出线方向找到断路器，再向两侧追踪隔离开关、CT、VT、接地开关与线路/变压器端；围绕这一串设备标注的回路名称，通常就是一个间隔的阅读起点。图纸符号、设备编号和布置方式由设计院图例与项目规范确定，下面只是原创示意，不可替代正式图纸。

  1. 从图签、图例、母线电压等级和回路名称确认阅读范围。
  2. 以断路器为锚点，沿电气连接辨认两侧的隔离开关、CT、VT、接地开关与一次设备。
  3. 记录设备位号和端子/二次图索引；再通过 SCL 中的 Bay、ConductingEquipment、LNode 追踪 IED 功能。
  4. 若图纸与 SCL 名称不一致，保留两者对应证据，不用名称猜测替代设计确认。

3. 一次设备与逻辑节点缩写速查

缩写是什么在自动化中的作用与边界
CTCurrent Transformer，电流互感器。把一次回路电流按额定变比转换为可供测量、保护或采样的二次量；CT 本身不是 IEC 61850 的通信服务。
VTVoltage Transformer，电压互感器；现场也可能称 PT。把一次电压转换为二次量，供测量、保护、同步或采样使用；准确等级、二次绕组和接线由设计资料确定。
XCBR断路器（Circuit Breaker）相关的逻辑节点类。用于表达断路器位置、状态、操作次数等相关模型数据；不是断路器本体，也不自动包含所有控制逻辑。
XSWI开关（Switch）相关的逻辑节点类。常用于隔离开关、接地开关等开关设备的状态/控制相关建模；具体对应何种一次开关必须结合工程资料。
MMXU测量（Measurement）相关的逻辑节点类。组织三相量、功率、频率等测量数据；数值仍要连同单位、倍率、质量 q 和时标 t 阅读。
TCTR电流互感器（Current Transformer）相关的逻辑节点类。表达 CT 相关的自动化模型信息；它不是 CT 的实物替代，也不能只凭存在 TCTR 推定采样链路。
CSWI开关控制（Switch Controller）相关的逻辑节点类。组织操作命令和控制过程；常与 XCBR/XSWI 的被控一次设备模型及 CILO 闭锁逻辑配合。
PTOC过流保护（Time Overcurrent Protection）相关的逻辑节点类。表达过流保护功能相关数据；整定、方向、配合、出口和投退必须再看具体模型与保护逻辑。
PTRC保护跳闸条件（Protection Trip Conditioning）相关的逻辑节点类。组织保护跳闸条件/出口相关数据，常位于多个保护判据与跳闸执行之间；不等于现场跳闸回路已闭合。
CILO闭锁（Interlocking）相关的逻辑节点类。表达开关操作闭锁相关状态或条件；是否准许操作还要结合 CSWI、权限、模式和现场安全措施。
CDCCommon Data Class，公共数据类。定义一类 DO 的典型属性结构和服务语义，如状态、测量或可控点；不是一个实时数据点或某个通信报文。

4. 常见功能组合：从设备到数据模型

组合正确理解
MMXU / TCTRTCTR 侧重电流互感器相关模型，MMXU 侧重测量功能；二者可与同一回路有关，但不是同义词。
XCBR / CSWIXCBR 面向断路器设备相关状态/模型；CSWI 面向开关控制。控制链还可能包含 CILO 和实际执行装置。
PTOC / PTRCPTOC 表达过流保护判据相关功能；PTRC 处理保护跳闸条件/出口相关功能。两者之间的具体逻辑因工程而异。

5. 站控层、间隔层与过程层

常见三层划分是帮助理解功能位置的逻辑视角，不是规定每台设备只能处于一层的物理机柜规则。用户任务中的“过程层、间隔层、过程层”这里按通常的“站控层、间隔层、过程层”补充。

层级定义与常见组成与模型/服务的连接
站控层面向全站运行、监视、协调和对外接口；常含 HMI、SCADA/站控服务器、网关、工程工作站。常经客户端/服务器服务访问 IED；可涉及报告、控制、IF1/IF6/IF7/IF9/IF10 等逻辑接口。
间隔层面向某一 Bay 的保护、测量、控制和自动化；常含保护与测控 IED。LN、DO、CDC 组织功能；可收 SV、发/收 GOOSE，亦可提供报告和控制服务。
过程层靠近一次过程，连接互感器、开关机构和现场 I/O；常含 MU、智能终端和相关一次接口。常见 SV 采样发布、GOOSE 状态/控制交换；CT/VT 与 XCBR 等一次对象仍需区分实物和模型。

6. 接到数据模型：不要让缩写停在图纸上

从图纸识别到 CT、VT 或断路器后，下一步不是直接从 IED 名猜业务，而是沿可追溯链路定位：Bay / ConductingEquipment → LNode → IED / LDevice / LN → DO / DA / FC → DataSet / 控制块 / 通信引用。例如，断路器相关的 XCBR 可包含位置等 DO；其状态、质量和时标往往位于相应 DA 中；控制功能还要继续核对 CSWI、CILO、ctlModel、权限与工程逻辑。

继续阅读：IED 与数据模型的“从一次设备到 LN、DO 与 CDC”补充，说明这些缩写如何进入数据对象、类型模板与服务引用；标准文库概论则回顾 ACSI 与 IF1～IF10。
