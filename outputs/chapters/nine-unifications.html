设计、制造、集成与运维人员需要对保护功能、接口和信息有一致理解。“九统一”是国内继电保护标准化设计语境中的常用称呼，覆盖功能、二次回路、端子、接口、压板、定值与报告、人机界面和信息规范等方面，既涉及常规二次回路，也涉及智能变电站模型与虚端子。

一手公开说明中，开普检测 2020 年招股说明书“释义”将其归于国家电网向生产厂商提出的技术标准要求，列出下述九方面。该资料解释称谓，不是规范条款或现行版本清单。南网工程须依据自身适用文件逐条核实，不能直接套用国网文号，也不预设两网共同发布了一份同名同条款的“九统一标准”。

正文、表格及案例为本站原创导读，不是标准原文。本页尚未取得可逐条核验两网现行要求的完整企业规范，因此不刊出未经证实的统一点号、固定压板清单、指示灯颜色或全网统一数据集成员。解释须与正式规范、设备手册及工程版本配套阅读。

九项内容：统一对象与工程落点

采用上述公开资料的九方面分法；有的资料合并指示灯与操作界面，或把配置文件单列。必须保留所读文件的名称、版次和条款，不能仅凭“九项”数量判断含义相同。

方面统一对象的理解查证材料与模型联系
1. 功能配置保护、辅助、监视与控制功能及其配置条件。配置原则、功能图、装置手册；出现 PTOC 不证明全部功能和性能合格。
2. 回路设计电流电压、直流电源、跳合闸、信号与闭锁等二次回路。原理图、回路图、内部逻辑；智能站还查 GOOSE/SV 虚回路，XML 可引用不证明整组功能成立。
3. 端子排布置屏柜和装置端子的分区、排列、编号及设计约定。端子排图、接线表、光纤配线；实体端子与虚端子的对应须有工程映射。
4. 接口标准接口类型、数量及技术要求，包括适用的电气、光口和通信接口。接口图与技术规范；AccessPoint、ConnectedAP 和服务声明只是部分证据。
5. 屏柜压板压板的功能、设置与标识，结合硬压板、软压板和出口关系理解。压板清单、内部逻辑及模型；区分状态、命令与许可，不将任一 GGIO 状态直接当出口许可。
6. 保护定值和报告格式定值及报告的名称、组织与表达格式。定值模板、定值单、动作/故障报告；报告格式范围大于 IEC 61850 RCB，参数组织与 SGCB 机制也分层阅读。
7. 面板显示灯装置指示信息的表达与识别约定。面板图、灯含义和复归说明；灯与远传信息的保持、复归机制可能不同。
8. 装置菜单本地界面、信息组织和操作路径。界面规范与操作手册；菜单名称不必与 LN、DO、DataSet 名一一对应。
9. 信息规范保护动作、告警、状态等输出信息的表达与组织。信息点表、模型规范、ICD/SCD 与接收映射；逐项核对语义、品质、时标及触发。

表格用于理解和查证，不提供设备配置合格判定。产品声明符合九统一，仍需核对它声明采用的具体文件、版本、范围与检测证据。

与 IEC 61850 的关系：从要求走到证据

设计与信息要求（功能、接口、信号含义及适用条款）
  ↓ 查设备模型和工程映射
IED / LD / LN / DO / DA + CDC / FC
  ↓ 按用途组织引用，核对成员顺序与类型
DataSet + ReportControl / GSEControl / SampledValueControl
  ↓ 查通信配置、接收声明与内部绑定
Communication / Inputs / ExtRef + 图纸、逻辑和点表
  ↓ 结合装置及工程验证记录
动作信息、出口与执行反馈的证据关系

IEC 61850 提供建模、配置和通信机制；企业标准化要求进一步约束工程如何使用这些机制。PTRC.Op 的模型语义与某项目“跳某断路器的哪一路出口”的绑定属于不同层次，DataSet 名称、APPID、MAC 或 IED 名不能独立证明后者。

虚端子是工程人员描述数字输入/输出接口及连接的常用语境。阅读 SCL 时通常需联查发布成员、控制块、通信参数、接收 ExtRef 与内部映射，单个 FCDA 或 ExtRef 不能等同于完整回路和设备逻辑。

用 dsTripInfo 贯通标准化阅读

常用 LD 与数据集专题给出参考 SCD 的一例：PROT/LLN0.dsTripInfo 包含起动和动作相关的 6 个 ST/FCD 成员，由缓冲报告控制块引用。下列为原创练习，不是九统一条款摘录，也不构成该工程符合九统一的证明：

  1. 信息语义：对照适用点表，区分起动、保护功能动作与跳闸调理；查 DO 描述及类型，不合称“断路器已跳”。
  2. 模型组织：确认所属 LD/LN、FC 和粒度。本例 FCD 包含结构化值、品质和时标，序号表须保留成员顺序。
  3. 上送方式：查 ReportControl；声明 BRCB 不等于运行中已经使能，也不等于使用 GOOSE 出口。
  4. 出口与反馈：另循 GSEControl/DataSet、接收 ExtRef 与内部逻辑追踪出口，用图纸、执行记录及位置反馈核对作用。
  5. 标准化核对：逐项记录正式规范条款、设备模型/手册版本及工程点表的对应关系；资料不足仅保留结构事实。

同一思路也用于 dsAlarm、dsWarning、dsRelayEna：先查成员与使用者，再对照规范确定含义。

常见误区与自检

九统一就是统一 IEC 61850 通信协议吗？

范围更广，还包括功能、回路、端子、接口、压板、定值与报告格式、界面及信息。通信互通只是部分机制。

出现 PROT 和 dsTripInfo 就能证明符合九统一吗？

不能，须核对适用规范、版本、条款及设计和验证证据。

国网规则可原样用于南网项目吗？

先核对项目采用文件及条款；共同使用 IEC 61850 不是企业要求相同的证据。

定值和报告格式统一，意味着固定 RCB 和定值区号吗？

不能这样推导。报告范围、通信报告机制、参数组织与组管理须分别核对。
