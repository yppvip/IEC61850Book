一次接线：从单线图认识设备与拓扑

先沿能量回路定位设备，再追踪测量、保护和控制。

先分清图纸层次

一次系统承担电能的输送、变换和分配；二次系统负责测量、保护、控制、信号与辅助供电。单线图重在电气连接；二次原理图重在互感器、接点、线圈与逻辑回路；端子图/接线图重在端子及电缆连接；SCD 重在模型和通信工程引用。四种材料能互相核对，但各自省略的信息不同。

一次设备各自解决什么问题

设备 / 常见缩写功能关联模型与限制
断路器 Circuit Breaker / CB（图中 QF）在规定能力内合、分正常电流和故障电流XCBR 表示断路器信息；线圈和机构完成物理动作。收到命令不代表已分位。
隔离开关 Disconnector / DS（图中 QS）提供隔离功能、建立隔离边界常关联 XSWI；一般不承担负荷或短路电流开断，特殊额定切换能力须查设备资料。
接地开关 Earthing Switch / ES将指定导体接地，供安全措施等使用与隔离开关、断路器有联锁关系；位置语义仍需查工程对象定义。
CT / VT（PT）测量电流 / 电压，并使测量保护回路获得适合的信号TCTR / TVTR 描述相应信息；可由常规互感器或其他传感器实现。
电力变压器 Power Transformer连接不同电压等级，并由接线组别等影响相位与零序通路不等同于测量用 CT/VT；YPTR、YLTC 等功能须按设备配置查证。
母线 Busbar / 线路 Line汇集回路 / 连接电网不同位置母线是电气导体，不是 Ethernet 总线；Busbar 与 station bus 语境不同。
避雷器 / 电容器 / 电抗器限制过电压 / 无功补偿 / 限流或无功调节等功能取决于实际接线；不能由一个设备名推定全部用途。

QF、QS 是本页助读代号，不是全行业统一设备编号。IEC 61850 LN 类名也不是一次图的图形符号。设备模型深入见X/T/Y 组。

母线、间隔与电气连接

一个间隔 Bay 围绕线路、主变或母联等回路组织设备和功能。单母线、分段、双母线等接线方式决定可连接路径；开关状态改变当前拓扑。母联连接母线系统，分段连接同一母线的分段；项目称谓须按图纸解释。

SCL 一次结构可用 Terminal 的 connectivityNode 引用 ConnectivityNode 表达连接。同一节点表示按模型声明的电气相连；它不同于 LN 的网络通信端点。只找 Bay 目录或统计 LN 数量不能得到完整实时拓扑，实时开关状态、模型完整性和应用规则还需另外核对。

二次回路与站用直流为何必须认识

常规方案中，CT/VT 二次回路把电气量送入装置；保护出口接点、控制电源、跳闸线圈和断路器机构构成执行链。站用直流系统通常由充电装置与蓄电池等组成，在站用交流异常时维持关键保护控制供电，具体配置以设计为准。

数字化方案用 MU、SV、GOOSE 和过程接口替代部分信号电缆，但传感器、机构、控制电源、接线与辅助接点仍然存在。网络连通不能证明跳闸直流回路完好。阅读到“出口成功、位置未变”时，应想到机构、电源、回路与反馈，不只想到 IP。

同一一次设备可由多个 LN 共同表达，一台 IED 也可以实现多种功能。继续看一次对象到 LNode / LN 的桥梁。

自检：图中哪些线不能当成网线

SCD 里有 XCBR，是否证明它一定连接到图中的断路器？ · 展开参考答案

不能。先核对 LNode、一次设备和接线/点表；再核对装置的实际 I/O 与试验记录。LN 类说明模型语义，不能独自证明物理绑定。

断路器分位是否足以认定已满足检修隔离？ · 展开参考答案

不能。分位只是一个设备状态，隔离、接地、验电与工作许可等由现场规程和实际措施确定。软件显示不能充当作业许可。
