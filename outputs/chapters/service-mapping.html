特定通信服务映射与报文格式

从抽象行为到具体编码：ACSI、SCSM、MMS、GOOSE 和 SV 的对应关系。

阅读位置与来源边界

上级：第 7-1 部分：原理与模型。按“概念 → 对象与属性 → SCD 证据 → 使用边界”阅读；本页是原创中文导读，不是标准原文或可投产配置。

本次基线为所给 IEC 61850:2003/2004 对应中文资料；参考 SCD 的根元素声明 version="2007"、revision="B"、release="4"。版本差异、工程实例和教学示例分别标注。XML 配置值不等于设备当前运行值。

1. 映射是什么意思

SCSM（Specific Communication Service Mapping，特定通信服务映射）把 ACSI 的类、对象引用、服务和参数变成某种协议的变量、请求、响应或发布消息。映射既包含“服务如何对应”，也包含“数据类型怎样编码”和“协议栈怎样承载”。SCL 是工程配置语言，XML 本身不是所有 IEC 61850 实时业务报文的格式。

2. 本次资料中已定义哪些映射

下表回答“标准如何映射这些服务”，不声称现场所有设备已经实现或启用。所给 8-1 与 9-2 为早期基线，现代 R-GOOSE/R-SV、其他新映射及安全扩展不归入本表的完整覆盖承诺。

3. ASN.1、BER、TLV 和 PDU

缩写英文全拼用途
ASN.1Abstract Syntax Notation One定义协议的数据结构和类型，例 SEQUENCE、CHOICE、INTEGER
BERBasic Encoding Rules将 ASN.1 值编码为字节的基本规则
TLVTag–Length–Value标签、长度、值的编码组织；长度需按规则解释
PDUProtocol Data Unit某个协议层的数据单元
APDUApplication Protocol Data Unit应用协议数据单元
ASDUApplication Service Data Unit应用服务数据单元；SV 可将多组装进一个 APDU
ACSEAssociation Control Service Element应用关联控制
TPKT / COTPISO Transport over TCP packet / Connection-Oriented Transport ProtocolMMS 常用 TCP 承载中的封装/传输部分

MMS 与 GOOSE 的值类型可在其协议结构中表达；SV 的 sample 内容使用映射规定的基础类型字节表示，不能认为每个采样通道都包含一个完整业务名和单位。字段树只展示编码结构，业务语义还需回到 DataSet/FCDA/类型模板。

4. 三类主要报文的层次

类别从外到内的常见层次关键字段
MMSEthernet → 可选 VLAN → IP → TCP（常用 102）→ TPKT/COTP → Session/Presentation/ACSE → MMS PDUinvokeID、请求/响应服务、变量引用、MMS Data；建关联与后续消息的封装可不同
GOOSEEthernet → 可选 VLAN → 0x88B8 → APPID/Length/Reserved → GOOSE APDUgocbRef、timeAllowedToLive、datSet、goID、t、stNum、sqNum、test、confRev、ndsCom、numDatSetEntries、allData
SV（所给 9-2）Ethernet → 可选 VLAN → 0x88BA → APPID/Length/Reserved → SavPdu → ASDU 序列noASDU、svID、datSet、smpCnt、confRev、refrTm、smpSynch、smpRate、sample，字段可选性按版次

MMS 操作参数写入 Pos.Oper，不能因此把 Write 服务一概叫作“普通值写入”；其状态机仍实现 ACSI 控制。GOOSE t 反映适用状态事件时间语义，重发并不必然是新事件；SV smpCnt 跟踪样本顺序，不能套用 GOOSE stNum 的含义。

5. 对象名与类型映射示例

原理引用：LD_A/XCBR1.Pos.stVal [ST]
MMS 变量示意：Domain=IED_ALD_A，Item=XCBR1$ST$Pos$stVal
控制变量示意：XCBR1$CO$Pos$Oper
GOOSE/SV：控制块引用 + 数据集顺序，结合类型解释成员值

LD 的 MMS 域名可能由 IED 名与 ldInst 组合，也可能采用适用模型中的显式 LD 名；这里只是原创示意。$ 是映射中的层次分隔，不能不加上下文地用它替换所有 SCL 路径；SCL 用独立 XML 属性组合引用。

基础语义常见编码关系限制
BOOLEANMMS 布尔值；SV 基础类型规则中的字节表示相同语义在不同映射里字节结构不同
Dbpos / Quality / Check位串或规定类型编码位顺序与长度按映射；不是按 XML 字符串逐字符传输
FLOAT32 / INT32浮点或有符号整数编码；SV 采用规定宽度与字节序量纲与比例不随每个值自动附带
Timestamp常用 UTC 秒/秒小数/时间品质结构传输分辨率不是设备时间准确度
DataSetMMS 命名变量列表 / 发布数据集引用与成员顺序成员替换或重排须维护相关配置版本

6. 如何与 SCD 联读

MMS：先确认服务器/AP/LD/LN，再定位 DO/DA 与 FC。GOOSE：用控制块引用和 DataSet 到发布 LN，并核对 GSE 网络配置；SV：核对 SampledValueControl、SMV、样本序号、ASDU 数、数据集顺序、单位/比例和接收引用。APPID、MAC 和流标识帮助匹配通信对象，不能独立推出“跳哪台断路器”。
