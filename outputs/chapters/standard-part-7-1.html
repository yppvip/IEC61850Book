3. 功能分解与三层两网

SAS（Substation Automation System，变电站自动化系统）把现场测量、保护、控制、监视和记录分配到不同功能层。站控层服务全站运行，间隔层承担间隔或设备相关保护测控，过程层接近传感器和执行器。站控网与过程网是承载域；层是功能分工，网是通信连接，两者不一一对应。

保护跳闸可以在不经过站控 HMI 的情况下完成；GOOSE 的业务和部署位置须由发布订阅关系证明。某些站采用硬接线过程接口、合并网络或一体化设备，三层概念仍可帮助分析功能。网络冗余 A/B 是另一个维度。详见 三层两网与设备缩写。

4. 从现实功能到信息模型

先把“保护线路”“操作断路器”等大功能分解为可复用功能单元，再选择标准 LN 类；给每个功能实例分配 DO，按 CDC 建立 DA。将若干 LN 组合到 LD，最终部署到 IED。功能分解不要求每个功能独占一台装置：一台保护 IED 可容纳多个保护段、测量、跳闸条件和设备接口 LN。

例如 XCBR1.Pos 是位置对象，而 Pos.stVal 是它的状态属性；Pos.ctlVal 或映射中的 Pos.Oper.ctlVal 是命令值。DPC 的状态有四态，命令却是分/合布尔值。对象名的含义由 LN/DO/CDC/命名空间共同决定。

7. 如何读形式化规范

记法含义读表方法
Class / Instance类描述结构规则；实例是设备中的具体对象XCBR 是类，XCBR1 是实例；DOType ID 是工程模板标识
Inheritance / Specialisation继承通用结构，并以功能/类型进一步专门化LN 继承公共信息；DPC 继承 DATA 服务并施加 FC 限制
Composition / Association组成关系 / 引用关联LN 组成 DO；控制块关联数据集，数据集引用成员
Attribute name / Type / Value range属性名、类型、允许域先确定 CDC 和基本类型，再解释枚举或数值范围
Presence：M、O、条件符号是否须出现在该类实例中它是模型存在条件，不是 true/false 数据值
FC / TrgOp访问分组 / 内部事件触发语义不能凭 FC=CO 推断已有操控权限
Request / Response+ / Response−请求、成功响应、错误响应操作成功响应与最终状态变化、命令终止分别解释
ObjectName / ObjectReference局部名字 / 完整引用LD/LN.DO.DA；映射可能用 $ 分隔，不改对象语义

规范中的 DAType（属性类型概念）不总等于 SCL 中的 <DAType> 元素：SCL 仅用 DAType/BDA 表达结构化属性；基本类型由 bType 描述，枚举由 EnumType 描述。

8. 命名空间与扩展：名字怎样保持可解释

信息所处层级意义
XML xmlnsSCL 文档/元素选择 XML 标签所属模式；与设备数据语义命名空间是不同用途
ldNsLLN0.NamPlt，LPL逻辑设备基准语义命名空间
lnNsLN.NamPlt，LPLLN 使用不同于继承基准的定义时，标明其语义来源
dataNsDO 的扩展信息，EX数据对象语义偏离上层命名空间时标明定义来源
cdcNs、cdcNameDO 的扩展信息，EXCDC 或属性结构偏离适用基准时给出 CDC 来源与名称
PrivateSCL 私有信息容器工具或厂商扩展；不自动拥有标准语义

继承的命名空间让多数标准对象无需重复完整标记；偏离定义的实例必须有足够信息消除歧义。两个对象都叫 Pos，也可能分别表示开关位置与机械方位，必须结合上层类和命名空间。工程模板 ID 任意取名不会改变 CDC/LN 的标准定义。

9. 新语义的三种定义方法

方法原创温度统计例子收益与限制
固定语义分别定义 TmpMean10、TmpMean60，单位和统计时窗固定直观；每增加统计时窗可能增加新名称
灵活语义TmpMean 配合统计时窗和开始时间等配置对象同名对象可配置；必须明确配置与值的关系
可复用 CDC定义带统计值、时窗和起点的扩展 CDC，再复用于不同 DO结构可复用；须定义完整类型、行为与命名空间，不能冒充标准 CDC

工程扩展应优先复用已有 LN、DO 和 CDC；只有已有语义不能满足时才定义新对象。新名字、数据类型、单位、值域、访问、触发、存在条件和服务行为要一起定义。“增加一个 XML 字段”不等于完成可互操作的模型扩展。
