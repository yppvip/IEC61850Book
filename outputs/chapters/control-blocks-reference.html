1. 数据属性与控制块是什么关系

DA 是数据对象的组成，承载业务值、品质、时间和配置。控制块是 LN 关联的服务控制对象，管理“怎样报告/记日志/发布/选择定值组”。控制块可以引用一个数据集；数据集再引用各 LN 中的 FCD/FCDA。控制块不是 Pos 的另一个 stVal，报告控制块也不是开关操作对象。

常见“属性集”说法正确定位SCD 组织
一个 DO 的属性集合CDC 定义的 DA 组成DOType/DA；结构 DA 指向 DAType/BDA
同一 FC 的属性集合FCD，按 FC 筛选 DO 属性DataSet/FCDA 省略 daName 并指定 fc
任选的一组数据DataSet，成员可来自多个 LNDataSet 内多个 FCDA，顺序须保留
控制块属性控制块自己的配置/状态ReportControl 等 XML 配置 + 设备运行时控制对象
报告选项/触发选项OptFields / TrgOps 位选项控制块的子元素，不是新建业务 DO

“属性集”不是在所有语境下都指同一个标准对象。先确定是在说 CDC 成员、FC 分组、DataSet 清单还是控制块的属性。

2. 报告控制块 RCB：缓存与非缓存

属性取值/类型功能与差异
RptID字符串报告标识
RptEnaBOOLEAN是否启用报告；不能从 buffered 推断其运行时值
DatSet引用被报告的数据集
ConfRevINT32U数据集/配置修订
OptFlds选项位集合sequence-number、report-time-stamp、reason-for-inclusion、data-set-name、data-reference、buffer-overflow、entryID、conf-revision 等按 BRCB/URCB 范围
BufTmINT32U，ms事件聚合缓冲时间；不是断线历史保留时长
SqNum序号，基线 INT16U报告序列控制；具体映射宽度和回绕按版次
TrgOpsdchg/qchg/dupd/integrity/GI事件条件及完整性/总召唤
IntgPdINT32U，ms周期完整性报告周期
GIBOOLEAN 请求一次总召唤；不同于 TrgOps 中允许 GI 的配置
PurgeBuf（BRCB）BOOLEAN 请求清空缓存的控制请求
EntryID / TimeOfEntry（BRCB）条目标识 / EntryTime恢复和区分缓存条目
Resv（URCB）BOOLEAN当前客户端保留
ResvTms / Owner（后续版）保留时长 / 所有者信息需查采用版次；不属于本次早期基线全集

SCL ReportControl 的 buffered=true/false 选择 BRCB/URCB 类，name/rptID/datSet/confRev/bufTime/intgPd/indexed 描述工程配置；子元素 TrgOps、OptFields、RptEnabled/ClientLN 描述触发、字段与客户端配置。运行时的 RptEna、序号、缓存条目标识不要求在 SCD 中以同名 XML 属性出现。

OptFields（B4 全部属性）目的
seqNum报告序号
timeStamp报告时间戳
dataSet数据集引用
reasonCode成员包含原因
dataRef数据引用
entryID条目标识
configRef配置修订字段选项，勿解释成任意 XML 文件链接
bufOvfl缓存溢出指示；B4 默认 true，其余上述选项默认 false
原报告的 OptFlds 与 SCL OptFields 写法不同；报告中的 inclusion-bitstring 指示哪些数据集成员被携带，其长度与成员顺序相关，不是全站数据表。

3. 日志控制块 LCB：概念及全部基线属性

LCB（Log Control Block）决定哪些数据集变化写入设备内 LOG。日志记录独立于客户端是否保持通信关联；客户端以后按时间/条目查询。一个 LOG 可由多个 LCB 写入，LCB 与 LOG 是两个对象。缓存报告面向事件传递，LOG 面向历史存储。

基线抽象属性类型/取值域用途
LCBName / LCBRefObjectName / ObjectReference控制块名 / 完整引用；由所在 LD/LN 上下文定位
LogEnaBOOLEAN是否记录；SCL 初始配置对应 logEna
DatSetObjectReference被监视的数据集；XML datSet 是局部引用配置
OptFlds.reason-for-inclusionBOOLEAN 选项是否记录条目的触发原因；XML reasonCode 相关
TrgOps / TrgOpdchg、qchg、dupd、integrity 的组合记录触发条件，基线日志不支持 GI
IntgPdINT32U，ms；0～4294967295完整性记录周期；0 不进行周期完整性记录
LogRefObjectReference实际存储的 LOG；多个 LCB 可引用同一 LOG
LOG 属性/条目字段类型与意义
LogName / LogRef日志名字和引用，定位存储对象
OldEntr / NewEntr最旧 / 最新可用条目标识，EntryID 类型
OldEntrTm / NewEntrTm最旧 / 最新条目入库时间，EntryTime
EntryID / TimeOfLog单个条目的唯一标识 / 记录时间
EntryData记录的数据值、对象引用及适用原因代码

以上依据 7-2 第 14.3 节。8-1 映射表中还出现 OldEnt/NewEnt、OldEntrTim/NewEntrTim 等组件写法，应按映射中的实际字段核对；它们反映所引用日志的状态，不应在 LogControl XML 中自行添加同名运行属性。8-1 基线将原因代码规定为日志内容，不把抽象 OptFlds 单独映射成同名 MMS 控制字段。

4. LogControl 的 B4 XML 完整属性集

此表针对参考 SCD 根元素所声明的 SCL 2007B4，补充早期本地第 6 部分资料不足之处；按模式继承关系展开，含 desc、name、datSet、intgPd。

XML 属性模式类型/默认功能
nametCBName，必需LCB 本地名字
desc字符串，可选人可读 XML 说明，不是 DA.d
datSettDataSetName，可选数据集引用，使用时须解析同一控制块所在 LN 的数据集
intgPdUINT32，可选，默认 0完整性记录周期，ms
ldInsttLDInst，可选日志目标 LD；省略按上下文解释
prefixtPrefix，可选，默认空日志目标 LN 前缀
lnClasstLNClassEnum，可选，默认 LLN0日志目标 LN 类
lnInsttLNInst，可选日志目标 LN 实例
logNametLogName，必需被引用 Log 元素名字
logEnaBOOLEAN，可选，默认 true初始记录使能
reasonCodeBOOLEAN，可选，默认 true条目包含原因代码的配置
bufTimeUINT32，可选，默认 0B4 模式允许的缓冲时间配置，ms；参考 SCD 未声明

子元素包括 Text、Private（通用说明/扩展）与可选 TrgOps；TrgOps 的五个 XML 属性为 dchg、qchg、dupd、period、gi，都是 BOOLEAN，默认分别 false/false/false/false/true。但日志服务语义不支持 GI，模式允许一个字段不等于服务支持该功能。LogControl 不建立一个含历史条目的 XML 数据库，Log 元素才声明日志对象。

<!-- 原创脱敏片段；省略父级和完整类型，不可直接投产 -->
<LogControl name="logStatus" datSet="dsStatus" logName="events"
            logEna="true" reasonCode="true" intgPd="0">
  <TrgOps dchg="true" qchg="false" dupd="false" period="false" gi="false"/>
</LogControl>
<Log name="events"/>

参考文件实际有 98 个 LogControl，全部明确写 logEna=true、intgPd=0；是否真正记录、保留多少条和能否检索，仍由设备运行及存储能力决定。

5. 采样值发布及全部基线抽象属性

SVC（Sampled Value Control）把有序采样数据集写入发送缓冲，由映射更新订户接收缓冲。MSVCB（Multicast Sampled Value Control Block）服务多播；USVCB（Unicast Sampled Value Control Block）服务单播并有客户端保留关系。样本数据通常来自 SAV，连续性、同步和顺序尤其重要。

抽象属性/选项类型或允许值用途
MsvCBNam / MsvCBRefObjectName / ObjectReferenceMSVCB 名与路径
UsvCBNam / UsvCBRefObjectName / ObjectReferenceUSVCB 名与路径
SvEnaBOOLEAN，基线默认 false是否使能传输；使能期间其他配置写入受限制
Resv（仅 USVCB）BOOLEAN客户端保留；关联终止时释放相关状态
MsvID / UsvIDVISIBLE STRING65（基线抽象类型）采样流标识，映射通常为 svID；不是网络 APPID
DatSetObjectReference采样数据集，成员和顺序决定样本语义
ConfRevINT32U；0 在基线中保留配置修订；成员、顺序与相关配置变化时维护
SmpRateINT16U（基线抽象类型）所给 7-2 按额定周期样本数解释；所给 9-2 映射表按每秒样本数描述，必须结合映射与工程配置核对
OptFlds.refresh-timeBOOLEAN是否带刷新时间 RefrTm
OptFlds.sample-synchronisedBOOLEAN是否带采样同步信息 SmpSynch
OptFlds.sample-rateBOOLEAN是否带采样率 SmpRate
表中类型来自所给 7-2：不能把它与 B4 XML 的 xs:unsignedInt、或 SV 报文字段字节数当成完全同一层的范围。采样率在不同资料/映射间有解释差异；读工程时优先确认版次、smpMod、额定频率及设备配置。

6. SampledValueControl 与 SmvOpts 的 B4 完整属性集

XML 属性（含继承）类型/域/默认功能
nametCBName，必需控制块名
desc字符串，可选XML 说明
datSettDataSetName，可选采样数据集引用
confRevUINT32，可选（模式继承字段）配置修订；实际使用需满足服务/映射要求
smvIDtMessageID，必需采样流标识
multicastBOOLEAN，默认 true多播或单播模型选择，不证明现场已发流
smpRateUINT32，必需采样率数值，解释依 smpMod
nofASDUUINT32，必需每个 APDU 中 ASDU 数；业务要求须 >0 且满足映射限制
smpModSmpPerPeriod / SmpPerSec / SecPerSmp；默认 SmpPerPeriod每额定周期 / 每秒 / 每样本秒数；B4 补充
securityEnableNone / Signature / SignatureAndEncryption；默认 NoneB4 安全配置选择；需设备和适用映射支持
SmvOpts 属性允许值/默认功能
refreshTimeBOOLEAN，默认 false刷新时间字段选项
sampleSynchronizedBOOLEAN，B4 fixed=true同步信息字段选项；不意味着设备当前已同步
sampleRateBOOLEAN，默认 false携带采样率字段
dataSetBOOLEAN，默认 false携带数据集引用字段
securityBOOLEAN，默认 false安全相关选项，具体效果按映射/能力
timestampBOOLEAN，默认 falseB4 的时间戳相关选项
synchSourceIdBOOLEAN，默认 falseB4 的同步源标识选项

通用子元素有 Text/Private；IEDName 描述接收方引用（可带 apRef、ldInst、prefix、lnClass、lnInst），它仍需与接收方模型核对。B4 还允许 Protocol=R-SV 的扩展声明；本站报文详解范围是所给 9-2 以太网映射，不据此声称路由采样已经在该工程实现。

参考 SCD 的 SmvOpts 使用了 dataRef，而核对的 B4 模式使用 dataSet；它是需要核实的版本/工具兼容差异，不能将 dataRef 列成 B4 合法字段。缺省项也必须依据相应模式解释，根版本声明本身不等于已通过模式校验。
<!-- 取参考文件中的数值关系，名称重新命名；按 B4 字段写法整理 -->
<SampledValueControl name="svA" datSet="dsSamples" smvID="TRAINING_SV_A"
  confRev="1" smpRate="80" nofASDU="1" multicast="true" smpMod="SmpPerPeriod">
  <SmvOpts refreshTime="false" sampleSynchronized="true" sampleRate="false"
           dataSet="false" security="false"/>
</SampledValueControl>

在额定频率 50 Hz、SmpPerPeriod 且每样本均发布的教学前提下，80×50=4000 样本/秒。nofASDU=1 时每帧一组样本；如每帧连续装入 8 组，则理想帧率是样本率/8。这些演算不能证明参考站实际采用 50 Hz、已经发送或网络负荷符合要求。sampleSynchronized=true 是字段配置，运行时同步状态还要读样本与时钟证据。

8. GOOSE 与定值组控制块

对象主要属性与域用途
GoCB（7-2 基线）GoCBName/GoCBRef、GoEna BOOLEAN、AppID 字符串（8-1 映射对应 GoID）、DatSet 引用、ConfRev INT32U、NdsCom BOOLEAN事件发布与投运需求状态；表/映射可有额外具体参数
GSEControl（SCL）name、desc、datSet、confRev、type=GOOSE/GSSE、appID 字符串；B4 另有 fixedOffs/securityEnable发布模型；XML appID 为 GoID 相关标识，不是网络 Address/P 的 APPID 数值
SGCB（7-2 基线）SGCBName/SGCBRef；NumOfSG、ActSG、EditSG；CnfEdit BOOLEAN；LActTm TimeStamp（所给 7-2 表 22）组数、激活组、编辑组、编辑确认、上次激活时间
SettingControl（SCL）numOfSGs≥1；actSG 默认 1；B4 可有 resvTmsLLN0 的定值组配置；运行时编辑状态不等于静态文件
DataSetname、desc；FCDA 的 ldInst/prefix/lnClass/lnInst/doName/daName/fc/ix按成员引用与顺序组织；并非所有 FCDA 属性在每一种引用中都必需

开关控制对象的 ctlModel 放在 Pos 等 DO 的 CF 属性中，不能把它搬进 ReportControl 或 GSEControl；控制服务、控制块与业务控制逻辑是三层不同概念。
