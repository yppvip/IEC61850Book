1. Quality 品质的全部字段

数值说明“是什么”，q 说明“这个值现在能信到什么程度”。Quality 是 PACKED LIST，语义上包含有效性、细化品质、来源、测试与闭锁。此版表 1 各分量标为 M；未支持的功能按规定默认处理，实际报文编码由映射决定，不能把表内行数当字节数。

属性路径类型全部值域 / 默认意义
validityCODED ENUMgood / invalid / reserved / questionable总有效性；invalid 不宜使用，questionable 由客户按应用判断
detailQualPACKED LIST下列 8 个 BOOLEAN 标志说明无效/可疑的原因
detailQual.overflowBOOLEANFALSE / TRUE超过所选数值类型表示能力
detailQual.outOfRangeBOOLEANFALSE / TRUE超过预设过程范围，数值可能仍能表示
detailQual.badReferenceBOOLEANFALSE / TRUE基准源无法校准/不可靠
detailQual.oscillatoryBOOLEANFALSE / TRUE状态输入过于频繁变化/抖动
detailQual.failureBOOLEANFALSE / TRUE检测出内外故障
detailQual.oldDataBOOLEANFALSE / TRUE更新超龄；保留值可能已过时
detailQual.inconsistentBOOLEANFALSE / TRUE检测出不一致
detailQual.inaccurateBOOLEANFALSE / TRUE未达到来源声明精度
sourceCODED ENUMprocess / substituted；默认 process来源为过程或取代
testBOOLEANFALSE / TRUE；默认 FALSE数据处于测试用途
operatorBlockedBOOLEANFALSE / TRUE；默认 FALSE操作员闭锁更新，应同时置 oldData

有效性通常用 2 位，8 个细化标志加 source/test/operatorBlocked 得到本版常见 13 位语义；bit 顺序与打包以所用 SCSM 为准。reserved 是保留编码，不是第四种可用有效性。Quality 与 TimeStamp 内的时间品质 TimeQuality 作用不同。

场景品质组合怎样理解
数值超过类型能力invalid + overflow不能仅截断后当真实值
超出配置量程但数值仍可表示questionable + outOfRange与正常区间告警区别
操作员冻结输入刷新operatorBlocked + oldData保留的是闭锁前值
合法取代值source=substituted，可同时 validity=good好品质不证明物理采集恢复
测试数据test=TRUE客户处理按测试策略，与原值真假无关
多级网关断链下层 q 及上层 oldData/有效性共同考虑上层看到的品质可受链路影响，不只来自传感器

细化标志并非任意独立组合：检测到相关异常应结合 validity 标记 invalid/questionable；6.2.3 节的未编号关系表进一步给出适用组合，不能从单一比特推导完整处理策略。

2. AnalogueValue 与 ScaledValueConfig

类型 / 字段基本类型域 / 条件解释
AnalogueValue.iINT32−2^31…2^31−1；GC_1整数表示
AnalogueValue.fFLOAT32浮点；GC_1工程量的浮点表示
ScaledValueConfig.scaleFactorFLOAT32M，非零比例系数
ScaledValueConfig.offsetFLOAT32M，非零偏移不是强制；本版要求定义值偏移量

i/f 至少有一个；两者都有时应保持一致。关系为 f = i × scaleFactor + offset。例如 i=1234、scaleFactor=0.1、offset=−5，则 f=118.4（所声明工程单位）。这与 units.multiplier 的十进制单位倍率是两层信息，不能重复乘倍率或跳过偏移。该数例为原创演算。

只有 f 时不要求换算配置；只有 i 时配置可离线交换；i/f 都有时按 AC_SCAV 必须提供。FLOAT32 的表示范围/精度不是传感器精度，也不能列成所有可能的实际测量值。

3. RangeConfig、死区与零点钳制

字段类型 / 条件用途
hhLimAnalogueValue / M高高限
hLimAnalogueValue / M高限
lLimAnalogueValue / M低限
llLimAnalogueValue / M低低限
minAnalogueValue / M最小过程量
maxAnalogueValue / M最大过程量
区间（由低到高）range品质含义
低于 minlow-lowquestionable + outOfRange
min 到 llLimlow-low在过程允许域内，品质可为 good
llLim 到 lLimlow品质可为 good
lLim 到 hLimnormal品质可为 good
hLim 到 hhLimhigh品质可为 good
hhLim 到 maxhigh-high品质可为 good
高于 maxhigh-highquestionable + outOfRange

阈值上的相等处理、回差及跨区事件过滤要查实现；上表表示区间关系，不替设备规定边界比较符。过程 min/max 与控制 minVal/maxVal 是不同字段。

db 决定何时更新 mag/cVal，zeroDb 决定零附近何时强制为 0。两者的 0…100000 对应 0…100%，每计数单位 0.001%。例如量程 0…200 A，db=500 表示 0.5%，简单差值算法阈值为 1 A；99.9→100.2 A 未越死区，不证明测量没刷新。积分死区另有时间量纲和当地算法。

类型.属性基本类型值域 / 条件用途
ValWithTrans.posValINT8−64…63；M步/档位置
ValWithTrans.transIndBOOLEANFALSE / TRUE；O是否在过渡中
PulseConfig.cmdQualENUMERATEDpulse / persistent；M脉冲/持续输出
PulseConfig.onDurINT32Ums；0 当地定义；M脉冲宽度
PulseConfig.offDurINT32Ums；0 当地定义；M脉冲间隔

Point.yValFLOAT32M曲线点纵坐标

原创脉冲例：onDur=100 ms，offDur=200 ms，numPls=3，生成三次 100 ms 输出，中间各间隔 200 ms。persistent 由当地控制逻辑决定停止，不能据此断言输出永久保持。位置例 posVal=5、transInd=TRUE 表示有位置编号且正在过渡；不能当稳定第 5 档。

6. Unit 与 Vector：mag 和 ang

类型.属性类型域 / 条件功能
Unit.SIUnitENUMERATED附录 A；M单位种类
Unit.multiplierENUMERATED十进制指数；O，默认 00→10^0=1，3→10^3，−3→10^−3
Vector.magAnalogueValueM复数值的模
Vector.angAnalogueValueO，单位为度复数值的幅角；基准由使用场合确定

例如 phsA.cVal.mag.f=10，units.SIUnit=A，multiplier=3，则为 10 kA；若 ang.f=−30，则表示相对 angRef 的 −30°。只有模时不能凭空补相角。CMV.angRef 的 V/A/other 与复合 WYE/DEL 的具体相参考不同；附录 A 单位全表 和 测量类 分别说明。

7. CtlModels 的五种控制模式

命名由两条轴组成：direct/sbo 表示直接操作或先选择；normal/enhanced-security 表示控制执行监督等级。SBO=Select Before Operate（操作前选择）。这里 security 主要是操作过程的可靠性/监督机制，不能当作加密或身份认证能力。

常用编码枚举文本含义 / 功能流程使用条件示例
0status-only只提供状态无 Select/Operate用于建模为可控类但本实例仅反馈
1direct-with-normal-security直接控制，一般安全Operate → 服务结果应用接受普通命令应答，不要求增强终结通知
2sbo-with-normal-security操作前选择，一般安全Select → Operate → 服务结果需要对象保留且普通应答足够
3direct-with-enhanced-security直接控制，增强安全Operate → 服务结果 → CommandTermination需要命令执行结束通知与状态监督
4sbo-with-enhanced-security操作前选择，增强安全SelectWithValue → Operate → 服务结果 → CommandTermination需要先保留对象/值并监督执行结束

增强模式区分命令受理与执行结束，通过 CommandTermination 等机制监督结果；命令成功受理不等于一次开关已到位。SelectWithValue 在增强 SBO 中将预选与请求值关联；它不是随便读一下对象。本文说明场景选择因素，不替项目选定控制模式。

原文第 6.12 节出现 enhenced 拼写，第 8 章与实际枚举常用 enhanced；索引保留错误拼写作为搜索别名，正文用 enhanced。

8. SboClasses：操作一次或多次

枚举含义 / 功能使用场景释放条件
operate-once完成相应操作流程后回到未选择状态一次开/合等独立请求再次操作前重新选择
operate-many操作后在选择超时前保持准备状态同一客户连续调节等，需要实现支持取消、超时或其他规定释放条件

sboTimeout 是时间参数，sboClass 是操作后状态规则，stSeld 是当前选择状态。三者不能互相代替。控制服务详解。

品质细化标志与有效性的组合

6.2.3 的关系表限定单项原因通常对应的有效性；多种原因同时发生还需综合处理。以下“✓”表示原表标出的关联，不是允许忽略其他故障。

detailQualinvalidquestionable适用对象 / 补充
overflow✓—测量；超出所用类型可表示范围
outOfRange✓✓测量；超出预设范围，服务器按情况判断
badReference✓✓测量/计数；基准异常
oscillatory✓✓状态输入；短时隐匿可疑，持续抖动无效
failure✓—检测出的内部/外部故障
oldData—✓未在规定时限更新
inconsistent—✓来源存在不一致
inaccurate—✓精度不足

原文 6.2.3 关系表没有表号；不能称为模拟值类型的“表 2”。表 2 实际是 AnalogueValue。振荡判定窗口 t_osc、允许隐匿次数、allowed-age 时限是实现/应用参数，不能从 q 本身读出阈值。

取代、闭锁与断链的四种组合

信息链情形（对照原图 3）上层观察解释
A：过程输入闭锁，未取代questionable / oldData保留输入可能过时；操作员闭锁还应标 operatorBlocked
B：过程侧已启用取代substituted替代值及其品质向上传递，不等于输入恢复
C：过程侧取代后，中间链路断开substituted + questionable / oldData保留的取代值也可能过时
D：链路断开，中间服务器再做取代中间层提供 substituted 及本层取代品质本层替代值可用与下层恢复是两件事

source、validity、test 与 operatorBlocked 表达不同维度。test 与真假值独立；闭锁通信更新和闭锁物理输入都可能造成 oldData，但 operatorBlocked 专门说明操作员闭锁。
