自动控制：目标、比较、执行与反馈

例：原创控制带中心 110 kV、总宽度 2 kV，可把目标带理解为 109～111 kV；实际设备的带宽定义、回差、延时和变比需核对。越过带边缘不等于立刻调挡，更不等于允许无限调挡。

ANCR：中性点电流调节

Neutral current regulation；中性点补偿电流自动调节，关联 YEFN 的线圈位置。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
LocSPSM—就地/远方位置状态；TRUE 为就地，FALSE 为远方。LD 与 LN 冲突时就地主导。
OpCntRsINCO—可复位逻辑节点动作计数
TapChgBSCM—表示步进或调节一挡分接开关位置过程控制
RColSPCO—可动铁心上升位置
LColSPCO—可动铁心最低位置
AutoSPCO—该数据允许或禁止自动控制器的输出电路输出

原文：5.9，PDF 51～52；工程观察：0 个实例。本工程未出现，不能借其他类同名数据充当此类证据。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
LocSPSM—就地/远方位置状态；TRUE 为就地，FALSE 为远方。LD 与 LN 冲突时就地主导。
OpCntRsINCO—可复位逻辑节点动作计数
TapChgBSCM—表示步进或调节一挡分接开关位置过程控制
AutoSPCO—该数据允许或禁止自动控制器的输出电路输出
VOvStSPSO—为TRUE时表示电压强制控制状态
NeutAlmSPSO—为TRUE时表示中性点告警
DschBlkSPSOT为TRUE时表示因电容器组处于放电状态，闭锁电容器组投入

ATCC：自动分接开关控制

Automatic tap changer control；调节分接开关以维持电压，结合负荷电流、环流、压降补偿和并列运行。TapChg/TapPos 至少一个（C）；控制器与 YLTC 执行部件分开。

继承：Mod、Beh、Health、NamPlt 公用必备信息。下表为本类另列项；同名专用要求优先按本表。

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
LocSPSM—就地/远方位置状态；TRUE 为就地，FALSE 为远方。LD 与 LN 冲突时就地主导。
OpCntRsINCO—可复位逻辑节点动作计数
TapChgBSCC—表示步进或调节一挡分接开关位置过程控制
TapPosISCC—表示变压器离散调节，例如，用于有载分接开关调节器调节分接开关到指定位置
ParOpDPCM—变压器处于并列运行状态
LTCBlkSPCO—为TRUE时表示有载分接开关控制闭锁〈禁止）
LTCDragRsSPCOT复位有载分接开关的高/低位置记忆，使记忆回到当前位置。
VRed1SPCO—第一级降压命令；含编号的数据沿对应实例解释。
VRed2SPCO—第二级降压命令。
CtlVMVM—变压器二次侧电压，用于电压控制
LodAMVO—变压器负荷侧电流
CircAMVO—并列运行变压器之间的被测环流（并列安装的变压器二次电流中一个分量）
PhAngMVO—假定正向潮流和 PF=1 参考时，负荷电流 LodA 的相角关系。
HiCtlVMVO—自上次复位以来·最高控制电压
LoCtlVMVO—自最近复位以来，最低控制电压
HiDmdAMVO—自上次复位以来，最大电流需求
AutoSPSO—该数据允许或禁止自动控制器的输出电路输出
HiTapPosINSO—自上次复位以来，最高分接开关位置
LoTapPosINSO—自上次复位以来，最低分接开关位置
BndCtrASGO—控制范围中心，假定正向潮流
BndWidASGO—控制电压范围，以电压或标称电压的百分数表示，假定正常正向潮流
CtlDlTmmsINGO—达到预定正向潮流控制点后动作之前的控制延时时间
LDCRASGO—额定电流与正向潮流参考下，线路电阻部分对应的压降补偿量。
LDCXASGO—额定电流与正向潮流参考下，线路电抗部分对应的压降补偿量。
BlkLVASGO—自动降压命令的最低控制电压边界（ATCC 中为模拟定值，不能当布尔量）。
BlkRVASGO—自动升压命令的最高控制电压边界（ATCC 中为模拟定值）。
RnbkRVASGO—运行返回/回差相关的升压侧控制电压参考，需与降压动作门槛及控制带一起解释。
LimLodAASGO—LodA（百分比）电流上限值·超过该数值，自动调节命令终止
LDCSPGO—线路压降补偿因子
TmDlChrSPGO—TRUE 表示线性延时特性，FALSE 表示反时限特性。
LDCZASGO—额定电流与正向潮流参考下，总阻抗对应的压降补偿量。
VRedValASGO—当x级降低电压激活时，减少电压范围中间值（百分数）
TapBlkRINGO—闭锁自动升挡命令时有载分接开关调节器的分接开关位置
TapBlkLINGO—闭锁自动降挡命令时有载分接开关调节器的分接开关位置

原文：5.9，PDF 52～54；工程观察：27 个实例。查看真实类型链

数据名 / 语义入口CDC / 属性入口M/O/C瞬态 T功能简述
