学习起点

先补电气直觉，再用编程经验理解模型

如果你能读 XML，却还不知道“10 kV 的电压量、CT 的二次值、保护动作和断路器分位”各指什么，从第 1 阶段开始。每一阶段都有前置知识、阅读链接与完成标志。

第一次学电气从电路、三相、功率和电能建立物理直觉。已有明确查阅对象搜索 LN、CDC、XML 标签或电气术语，进入对应专题。

推荐学习顺序

沿 8 个阶段，把知识连成一条线

  1. 01

    先建立电气量的直觉

    知道设备承载什么

    电路、三相电与功率

    完成标志：能解释 10 kV、200 A、kW 与 kWh 分别是什么，说明公式的条件。

  2. 02

    看懂一次系统

    先看能量路径，再看信息路径

    一次接线与设备 → 一次系统与设备角色

    完成标志：能区分断路器、隔离开关、接地开关、CT、VT 和变压器；沿图定位间隔。

  3. 03

    理解测量与保护

    物理量如何变成数据，故障如何被切除

    互感器、采样与信号 → 保护、控制与跳闸闭环 → 保护 IED 功能范围

    完成标志：能追踪采样→判据→出口→反馈，解释通信成功与设备动作的区别。

  4. 04

    放回变电站自动化架构

    把设备和功能放进层级

    间隔与自动化层级 → 三层两网 → 易混概念对照 → ACSI 抽象接口

    完成标志：能解释一次/二次、站控/间隔/过程层，以及网络与逻辑层级的区别。

  5. 05

    进入标准信息模型

    从领域对象到类型与实例

    IED → LN → DO → DA → 属性和值 → 品质、时间与公用类型 → 控制和输入

    完成标志：能沿一个 DO 找到 CDC、FC、q/t、单位与枚举来源。

  6. 06

    阅读工程配置

    用 XML 引用形成可核对证据

    工程交换文件 → 十分钟读懂 SCD → 引用追踪工具箱 → 最小 XML 示例 → 数据集与控制块

    完成标志：能按实例和类型两个方向追踪 FCDA、控制块和订阅，识别缺失证据。

  7. 07

    学习通信与软件语义

    模型、服务与传输分别核对

    通信与过程层 → ACSI 服务 → 服务映射 → 静态协议字段 → 开发人员的数据契约

    完成标志：能分清 SV、GOOSE、Report 与控制；正确处理质量、时间、重复与失效。

  8. 08

    完成静态工程练习

    把所学串成证据链

    馈线综合练习与答案 → 工程证据核查 → 变更与交付 → 分层排障 → 安全与测试边界

    完成标志：能列出配置能证明什么、还缺什么；不以名称或报文到达代替业务和现场证据。
