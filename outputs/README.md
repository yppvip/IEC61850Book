## 离线与内容边界

- 所有页面、样式、脚本和术语数据均使用本地相对路径；没有 CDN、在线字体或在线 API。
- 本项目不提供抓包导入、报文解析、实时网卡操作、上传、发送、重放或注入功能。
- 教学片段为原创且脱敏的结构示例，不是完整可投产配置；内容不替代项目规范、设备手册、标准原文、工程校验或现场试验。
